## 스코프

- 주장 지명·경매의 역할 선고정 확정(2026-09-16). 네 방식의 진행·공유 연출은 [기준안 v0.1](../../02-design/formation-modes.md)에서 검토한다. 시간·예산·예외 규칙 등은 제안이며 구현·검증 완료로 처리하지 않는다.
- 기본 명단 입력은 최근 참여순 클랜원 목록에서 운영진이 직접 선택(2026-09-16 사용자 확정·기존 정렬 설계 확인). 출전자 10명 유지·라운드 사이 교체라는 기존 운영 방식에 맞춰 [D-UX-01 논의](../product-design-evolution.md#ux-01)에서 수동 UI/UX를 확정했다. 실제 앱 적용은 별도다.
- 확정한 수동 명단은 좌우 5칸, 각 팀 **딜·딜·탱·힐·힐** 고정과 중앙 역할 아이콘을 사용한다. 관전자 등록은 제외한다. 이름 클릭 → 고정 순서 첫 빈칸 입력, 자리 우클릭 → 비우기, 위 명단 드래그 → 빈칸 이동/두 사람 교환. 선택자는 하단 후보에서 숨기고 명단에서 빼면 기존 정렬 위치에 돌려놓는다. 되돌리기·리셋은 참여자 영역 우상단 아이콘으로 두며 리셋도 한 번에 복구한다. 별도 자리 선택·교환 모드·반복 위치 문구·체크·색상 범례·`되돌렸습니다`·`화면안 · 예시 명단` 표시는 제거한다. 모바일·저장·추가 편의성 후보는 `D-UX-01`에서 별도로 구체화한다.
- 대기방 화면 연결은 프로젝트 적용 방향 확정(2026-09-16). OCR 명단 후보와 수동 선택의 합류를 구현 대상으로 포함한다. 게임사 문의는 후속이며 실제 구현·검증은 미완료다. 플랜 범위·세부 UX는 미결이다.
- 집계일(KST 06:00 기준), 밸런스장 단독 배치 편집, 배치 완료 → 밴픽 → 경기 시작
- 수동(M)·자동(A) 점수 표기: **Premium**에서만 A 관련 UI (Free는 M 고정 등)
- 승부예측 마감 타이밍, Premium: 자동 밸런스·OCR·디스코드 알림(선택)
- 경기 슬롯 네임플레이트(프리셋만)
