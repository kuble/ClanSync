## 발급과 적용 범위

- 내전은 승·무·패가 하나 이상 기록된 개설 회차당 1회로 확정했다. 정규/깜짝을 구분하고 `team1`·`team2`·`draw`를 유효 결과로 보며 `void`·`unrecorded`만 있는 회차는 제외한다. 한 회차에 여러 경기 결과가 있어도 1회다.
- 장기 동료는 현재 같은 클랜의 활성 멤버 10명 이상이 각각 연속 1/3/5/10년을 채우는 조건이다. 창단 나이로 대신 판정하지 않는다. 가입 시작일이 없거나 연속성을 확인할 수 없는 기록은 달성을 추정하지 않는다.
- 코칭은 클랜 전체의 현재 완료된 피드백 신청 고유 건수, 게시글은 자유 게시판의 현재 고유 글 수다. 댓글·편집·반복 완료는 별도 횟수가 아니다. 삭제·완료 취소로 조건 미달이면 남은 최고 단계로 돌아간다.
- 내전/장기 동료/코칭/게시글은 계열별 최고 달성 하나와 전체 단계 상세를 사용한다. 첫 정규 내전은 단계가 없는 독립 기념 핀이다.
- 선택한 21개 단계를 QA에 적용했다. 창단·주년·멤버를 포함해 현재 30종이며 단계형은 최고 달성 한 슬롯, 첫 정규는 독립 기념 핀이다. 운영 DB/배포는 보류한다.

요청 기준·현재 기록과의 연결은 [확장 명세](../../../01-plan/clan-badge-expansion-v1.md)에 둔다. 각 계열의 `prompts.json`은 내장 `image_gen.imagegen`의 전체 요청과 원본 제작 기록이다.

## 파일 확인

30개 PNG의 단계·숫자·그림을 확인했다. 단계 비교 25장은 1942×809px, 첫 정규 내전 단독 5장은 1254×1254px의 투명 PNG다. 생성 원본을 수정 없이 복사했으며 SHA-256·크기·투명 모서리는 [에셋 목록](assets.json)에 기록했다.
