# 게임 선택 상세 설계

작성일: 2026-10-24 · 상태: **상세 설계 제안 / 검토용 / 구현 전**

적용 경로: `/games`. 공통 치수·색·표면·헤더·접근성은 [공통 설계](README.md)를 따른다.
앞 흐름: [랜딩](00-landing.md) · [로그인](01-sign-in.md) · [회원가입](02-sign-up.md).
다음 흐름: [게임 계정 연결](05-game-auth.md) · [클랜 가입](03-clan-join.md).

## 1. 화면의 역할

사용자가 이어갈 게임과 다음 행동을 고르는 개인 시작 화면이다. 소속이 있으면 클랜에 들어가고, 신청 중이면 상태를 확인하며, 처음이면 계정을 연결한다.
게임 하나만 있어도 자동 이동하지 않는다. 다른 게임·프로필·로그아웃에 접근할 수 있는 선택 화면을 유지한다.
가입을 마치지 않았거나 게임 연결이 없어도 `/profile` 접근을 막지 않는다.

## 2. 현재와 변경안

| 항목 | 현재 | 변경안 |
| --- | --- | --- |
| 카드 | 큰 16:9 이모지 영역 + 이름 + 상태 | 게임 아이콘 + 전체 ID + 현재 소속/신청 + 이동 문구 |
| 목록 | 모든 게임을 같은 3열 카드로 배치 | 이용 중인 게임 → 다른 게임 → 지원 예정 |
| 검색 | 게임 수와 무관하게 상시 표시 | 활성 게임 7개 이상일 때만 표시하는 초안 |
| 인증 정보 | 인증 여부만 조회 | 본인의 표시용 전체 게임 ID를 함께 조회 |
| 제공 상태 | `games.is_active`로 카드 활성 결정 | 게임 활성과 실제 연결 제공 여부를 별도로 설명 |
| 계정 메뉴 | 이메일·프로필·로그아웃 | 계정 메뉴 유지, 이메일은 펼쳤을 때만 표시 |

## 3. 데스크톱 배치

```text
[ClanSync / 게임 선택]                         [테마] [계정 메뉴]

게임 선택
플레이할 게임에서 클랜 활동을 이어가세요.
[게임 검색: 활성 게임이 많을 때만]

이용 중인 게임
┌ 오버워치                         ┐ ┌ 발로란트                     ┐
│ [게임 아이콘]  AimZero#12345     │ │ [게임 아이콘]  Player#KR1    │
│ 우리 클랜 · 소속 중              │ │ 함께할 클랜 · 승인 대기       │
│ 클랜으로 이동 →                 │ │ 신청 확인 →                  │
└─────────────────────────────────┘ └─────────────────────────────┘

다른 게임
[게임 아이콘 · 게임명 | 계정 미연결 | 게임 계정 연결 →]

지원 예정
리그 오브 레전드 · PUBG
```

본문은 공통 최대 폭을 사용하며 정보 카드는 최대 2열이다. 카드가 하나면 불필요하게 화면 전체 너비로 늘리지 않는다.
카드 내부는 아이콘·게임명, ID, 소속/신청, 행동의 순서다. 카드 아래 별도 판촉 배너는 두지 않는다.

## 4. 모바일 배치

```text
[ClanSync / 게임 선택]       [테마] [계정]
게임 선택
플레이할 게임에서 클랜 활동을 이어가세요.
이용 중인 게임
[아이콘] 오버워치
         AimZero#12345
         우리 클랜 · 소속 중
         클랜으로 이동 →
[아이콘] 발로란트
         Player#KR1
         함께할 클랜 · 승인 대기
         신청 확인 →
다른 게임
지원 예정 · 리그 오브 레전드 · PUBG
```

모든 카드는 1열이다. 320px에서도 전체 ID와 클랜명이 잘리지 않도록 줄바꿈하며 작은 카드 가로 스크롤을 만들지 않는다.
메뉴는 화면 밖으로 넘치지 않게 오른쪽에 붙인다. 메뉴를 닫으면 초점은 계정 메뉴 버튼으로 돌아온다.

## 5. 요소·문구·그룹 규칙

| 순서 | 요소 | 문구·동작 |
| --- | --- | --- |
| 1 | 공통 헤더 | 로고는 `/?from=logo`, 현재 위치 `게임 선택`, 테마, 계정 메뉴 |
| 2 | 계정 메뉴 | `내 계정`, 본인 이메일, `프로필`, `로그아웃` |
| 3 | 페이지 제목·설명 | `게임 선택` / `플레이할 게임에서 클랜 활동을 이어가세요.` |
| 4 | 선택적 검색 | 레이블·placeholder `게임 검색`, 한글/영문/기존 별칭 검색 |
| 5 | 이용 중인 게임 | 현재 연결 정보 행·소속·진행 중 신청 중 하나라도 있는 활성 게임 |
| 6 | 다른 게임 | 위 그룹에 포함되지 않은 활성 게임. 첫 사용자는 이 목록을 바로 표시 |
| 7 | 지원 예정 | 비활성 게임의 이름과 아이콘만 작은 목록에 표시. 클릭·탭 정지 없음 |

빈 그룹 제목은 생략한다. 같은 게임은 한 번만 표시하며 과거 접속·탈퇴·신청 이력을 새로 조회하지 않는다.
그룹 안 순서는 현재 게임 순서를 유지한다. 최근 접속 수집이나 자동 추천 순위를 추가하지 않는다.
아이콘은 기존 `GameLogo`를 재사용한다. 현재 실제 로고 자산은 오버워치이며 다른 게임은 공통 게임 아이콘으로 대체한다.
전체 ID는 배틀태그 `이름#번호`, 라이엇 ID `이름#태그`를 그대로 표시한다. 공통 닉네임·이메일·내부 제공자 ID로 대체하지 않는다.
연결 행이 있지만 ID가 없으면 `게임 ID 미등록`을 표시한다. 인증 여부와 표시용 ID 존재 여부를 같은 값으로 취급하지 않는다.
카드 전체는 링크 하나다. 화살표·행동 문구도 같은 링크 안에 두고 중첩 버튼이나 별도 클릭 영역을 만들지 않는다.

## 6. 상태·이동 표

| 게임 상태 | 카드 정보 | 행동 | 목적지 |
| --- | --- | --- | --- |
| 인증됨·소속 있음 | 전체 ID, 클랜명, `소속 중` | `클랜으로 이동` | `/games/{gameSlug}/clan/{clanId}` |
| 인증됨·신청 중 | 전체 ID, 신청 클랜명, `승인 대기` | `신청 확인` | `/games/{gameSlug}/clan?pending=1` |
| 인증됨·미소속 | 전체 ID, `함께할 클랜을 찾아보세요` | `클랜 찾기` | `/games/{gameSlug}/clan` |
| 미인증·미소속 | `계정 미연결` | `게임 계정 연결` | `/games/{gameSlug}/auth` |
| 미인증·신청 중 | 클랜명, `신청 대기 · 계정 확인 필요` | `계정 연결 계속` | `/games/{gameSlug}/auth` |
| 미인증·소속 있음 | 클랜명, `계정 확인 필요` | `게임 계정 다시 연결` | `/games/{gameSlug}/auth?reauth=1` |
| 게임 비활성 | `지원 예정` | 없음 | 링크가 없는 일반 목록 항목 |
| 활성·신규 연결 미제공 | 위 소속·신청 정보와 `신규 연결 준비 중` | 미인증이면 `연결 상태 보기` | 해당 게임의 연결 안내 화면 |
| 조회 실패 | 해당 데이터 영역 오류 | `다시 불러오기` | `/games` 재요청 |

비활성 상태가 카드 이동보다 우선한다. 운영 신규 연결 미제공이어도 인증된 기존 회원의 클랜 이동은 막지 않는다.
목적지는 기존 [카드 라우터](../../../src/lib/routing/game-card-router.ts)를 기준으로 만들며 클릭 후 서버가 최신 인증·소속을 다시 판정한다.
신청 보류 문구는 인증 미완료를 설명할 뿐, 신청 DB 상태를 새 상태로 바꾸거나 자동 취소한다는 뜻이 아니다.

## 7. 데이터와 실패 처리

| 구분 | 필요한 정보·처리 |
| --- | --- |
| 기존 조회 | `games(id, slug, name_ko, is_active)`, 본인 인증 여부, 게임별 활성 소속, 본인 진행 중 신청 |
| 본인 조회 확장 | 본인 `user_game_profiles`의 행 존재와 `battle_tag, riot_id, game_uid`; 표시용 ID 판별은 기존 도우미 재사용 |
| 파생 제공 상태 | 게임 활성 여부 + 제공자 설정 + 서버의 시뮬레이터 허용 여부로 `QA 테스트 / 연결 준비 중 / 지원 예정` 구분 |
| 추가하지 않음 | 접속률, 추천 점수, 타인의 ID, 게임별 회원 통계, 최근 접속 저장 |

게임 목록·인증·소속·신청 중 하나라도 실패하면 미소속/미연결로 대신 표시하지 않는다. 제목·헤더는 유지하고 목록 안에 오류와 재시도를 둔다.
신청 클랜명만 조회하지 못하면 `가입 신청 진행 중`으로 표시하고 원래 신청 ID·클랜 ID는 보존한다.
처음 로딩은 카드와 같은 외곽 높이의 자리표시자를 사용한다. 갱신 중 기존 카드를 유지하되 최신 상태를 확인하기 전 추가 행동은 막는다.
계정 변경·로그아웃 시 이전 사용자의 ID·클랜명·신청 결과를 폐기한다. 전체 ID를 분석 로그나 URL 검색어에 추가하지 않는다.
검색 결과가 없으면 `검색한 게임이 없어요. 다른 이름으로 검색해 주세요.`와 `검색 초기화`를 같은 영역에 표시한다.
등록 게임이 없으면 `아직 이용 가능한 게임이 없어요.`와 프로필 이동을 제공한다. 지원 예정 목록은 그대로 유지한다.

## 8. 수용 시나리오와 구현 경계

- 신규 계정: 빈 이용 중 그룹 없이 활성 게임이 보이며 프로필·로그아웃을 사용할 수 있다.
- 인증/소속 6조합: 표의 문구와 목적지가 일치하고 카드에 하나의 키보드 초점만 생긴다.
- 다중 게임: 게임별 전체 ID·클랜·신청을 섞지 않고 동일 게임을 두 그룹에 중복 표시하지 않는다.
- 운영 연결 미제공: 작동하는 OAuth처럼 표시하지 않으며 인증된 기존 소속 카드는 정상 이동한다.
- 긴 ID·클랜명, 320/390/768/1280px, 다크/라이트에서 읽기 순서와 조작 크기를 유지한다.
- 조회 오류·재시도·계정 전환: 잘못된 미소속 카드나 이전 사용자의 정보를 노출하지 않는다.
- 검색 조건과 카드 상태를 바꿔도 제목·헤더를 통째로 재생성하지 않는다.
