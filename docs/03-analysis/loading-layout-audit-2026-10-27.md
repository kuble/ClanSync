# 로딩 배치 점검 — 2026-10-27

기존 QA 데이터를 보존하고 클라이언트 조회 분기·페이지 로딩 경계·차트의 빈 상태를 확인했다. 조회 대상이 달라질 때 이전 응답을 새 데이터처럼 표시하지 않는 기준은 유지한다.

HoF 순위/댓글은 기존 36rem 카드, 경기 상세/당일 표는 560px, 맵 범례는 224px로 이미 영역을 유지한다. Discord 채널은 동일한 선택 상자 안에서 갱신하고 미니룸은 기존 방을 유지하며 갱신하므로 이번 변경에서 제외했다. 이미지 슬롯은 기존 크기/비율을 사용한다. 경기 단계 변경·편집 창 열기 등 사용자가 요청한 화면 전환은 로딩으로 취급하지 않는다.

첫 서버 응답 전에 아직 알 수 없는 이름·개수·권한별 내용은 실제 값처럼 꾸미지 않고 해당 영역의 자리 표시자로 표시한다. 게시판·관리·목록의 긴 내용은 예약한 영역 안에서 스크롤한다.

통계의 오류/재시도 안내는 항상 예약한 상태 줄에서 표시한다. 기존 절대 위치 안내가 새로 유지되는 필터 위에 겹치던 문제를 지연 검증에서 발견해 제거했다. 긴 오류 문구는 시각적으로 말줄임하고 전체 텍스트와 재시도 버튼은 유지한다. 스크롤 영역은 키보드 포커스를 제공한다.
