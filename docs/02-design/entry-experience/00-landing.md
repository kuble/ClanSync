# 랜딩 재기획 초안

작성일: 2026-10-24 · 갱신: 2026-10-30 · 상태: **첫 화면 중앙형 시안 검토 중 / 공개 랜딩 적용 전** · 경로: `/`

상위: [진입 변경 기획](../../01-plan/entry-experience-redesign.md) · [공통 기준](README.md)

2026-10-30 사용자가 선택한 방향을 반영한다. 기존 클랜 홈·프로필 중심 제안을 대체하며 랜딩의 구도·시각 방향은 이 문서가 우선한다. 다른 진입 화면은 이번 범위에서 제외한다.

## 1. 목적과 결정 상태

| 관점 | 기획 요약 |
| --- | --- |
| 문제 | 클랜장·운영진이 내전 참가자를 모으고 균형을 고려해 팀을 나누는 일이 번거롭다. |
| 해결 방향 | 모집·편성·조정의 실제 서비스 화면으로 운영 도구의 쓰임을 설명한다. |
| 방문 경험 | 소개 → 실제 편성 화면 → 운영 흐름 → 결과 기록 → 이용 안내 → 시작하기 |
| 전달 가치 | 내전 준비를 한곳에서 진행하고 경기 이후의 기록까지 이어간다. |

**사용자 선택:** 클랜 운영의 편리함, 클랜장·운영진 중심, 참가자 모집과 팀 편성 문제, 실제 편성 화면 중심, 밝고 차분한 운영 도구의 분위기.

**검토할 제안:** 첫 화면의 보조 행동·중앙 배치·하단 섹션 구성과 문구·이미지 크롭·시각 수치. 실제 운영자가 현재 사용하는 도구는 아직 확인하지 않았으므로 특정 채팅·문서를 쓴다는 가정이나 절약 시간 수치를 홍보에 사용하지 않는다.

## 2. 첫 화면과 확정 문구

2026-10-30 사용자가 아래 제목·설명·주 버튼 문구를 선택했다. 제목의 두 줄 구분은 PC 기준이며 작은 화면에서는 의미 단위로 자연스럽게 줄바꿈한다.

**제목**

> 팀 편성이 한결 편해지는
> 우리 클랜의 내전 도구.

**설명**

> 참가자 모집부터 팀 편성과 조정까지, 한곳에서 진행할 수 있습니다. ClanSync가 편성을 돕고, 운영진이 원하는 구성으로 마무리합니다.

확정한 주 행동은 `무료로 시작하기`다. 보조 행동은 `편성 화면 살펴보기 ↓`를 제안하며 대표 이미지의 `#formation-preview`로 이동한다. 실제 기능 체험을 의미하지 않는다.

```text
[ClanSync]                                    [테마] [로그인] [시작하기]

                  팀 편성이 한결 편해지는
                  우리 클랜의 내전 도구.
                  짧은 설명 · 무료로 시작하기
                    편성 화면 살펴보기 ↓

       [ 참가자 명단 · A팀/B팀 · 실제 서비스 화면 ]
                     내전 편성 · 예시 화면

[ 참가자를 모으고 ]        설명 + 실제 화면 일부
[ 팀을 나누고 조정하고 ]   설명 + 실제 화면 일부
[ 경기가 끝나면 기록으로 ] 설명 + 실제 화면 일부
[ 지원 게임 · 무료 이용 범위 · 제공 상태 ]
[ 다음 내전을 준비하십시오.                무료로 시작하기 ]
[ 하단 정보 ]
```

큰 화면은 중앙 제목 아래 넓은 편성 화면을 배치한다. 1280×720에서 제목·버튼과 대표 화면의 시작 부분을 함께 볼 수 있도록 하며 화면 전체를 한 뷰포트에 억지로 축소하지 않는다. 모바일도 소개 → 버튼 → 화면 순서이며 390×844에서 버튼이 큰 이미지보다 먼저 보이게 한다.

헤더의 시작 버튼은 본문 버튼이 보이지 않는 스크롤 위치에서도 진입을 제공한다. 각 설명 구간에 가입 버튼을 반복하지 않고 마지막에 한 번 더 제공한다. 소개 위·옆에 부가 카드나 기능 목록을 두지 않는다.

## 3. 섹션별 내용

| 순서 | 제목 초안 | 설명 초안 | 장면 |
| --- | --- | --- | --- |
| 1 | 참가자를 모으고 | 내전 참여 현황을 한곳에서 확인하십시오. | 실제 참가자 목록 |
| 2 | 팀을 나누고 조정하고 | 팀을 편성하고 필요한 조정을 이어가십시오. | 실제 두 팀과 운영진의 조정 화면 |
| 3 | 경기가 끝나면 기록으로 | 경기 결과를 남기고 멤버별 기록을 확인하십시오. | 결과·통계의 대표 부분 |
| 4 | 이용 안내 | 지원 게임과 무료 이용 범위를 확인하십시오. | 간결한 정보 행 |
| 5 | 다음 내전을 준비하십시오. | 긴 설명 없이 시작 행동 제공 | 무료로 시작하기 |

모집·편성·조정은 하나의 운영 흐름으로 읽히게 한다. 완벽한 밸런스나 원클릭 완료를 약속하지 않는다. 역할·편성 방식의 세부 명칭은 실제 촬영 화면과 함께 검토한다.

PC는 이미지와 짧은 설명을 짝지은 좌우 교대 구도를 제안한다. 모바일은 설명 다음 이미지다. 경기 기록 아래의 클랜 활동 섹션에서 일정·소통·꾸미기를 묶고 참여 추이·개인 기록·명예의 전당을 함께 소개한다. 스크림·대진표·프로필은 독립 섹션에서 제외한다.

## 4. 시각 방향과 대안

선택한 방향은 **밝고 차분한 운영 도구**다. 흰색 또는 아주 옅은 중성 배경, 짙은 본문, 기존 브랜드 계열의 강조색 하나를 사용한다. 색상값은 기존 토큰과 함께 시안에서 검토한다.

- 큰 제목과 넉넉한 여백으로 위계를 만든다. 대표 화면에는 얇은 테두리와 약한 그림자만 제안한다.
- 섹션 전체를 각각 카드로 감싸지 않는다. 글로우·대형 그라데이션·입체 장식·게임 캐릭터 배경은 제외한다.
- 기본 표현은 라이트다. 기존 테마 선택은 유지하고 방문자의 테마를 강제로 바꾸지 않는다. 다크에서도 같은 위계와 대비를 제공한다.
- 본문 폭 1200~1280px, 모바일 좌우 16~20px, 제목 PC 48~64px·모바일 30~36px를 시안 검토의 출발점으로 삼는다.

| 대안 | 장점 | 판단 |
| --- | --- | --- |
| 실제 편성 화면 중심 | 도구와 사용 장면을 직접 이해할 수 있음 | 사용자 선택 |
| 단순화한 흐름 그래픽 | 작은 화면에서 흐름을 쉽게 읽을 수 있음 | 대표 표현에서 제외. 필요 시 보조로 재검토 |
| 기존 화면의 간격·카드만 정리 | 변경 범위가 작음 | 처음부터 재기획한다는 요청에 따라 제외 |

## 5. 이미지 제작 기준

- 실제 QA 화면에서 참가자 명단과 편성된 두 팀이 동시에 보이는 단계를 선정한다. 공개용 별도 예시 데이터와 촬영본은 준비 전이다.
- 사용자 테스트 명단을 수정하거나 시드를 재실행하지 않는다. 공개용 예시는 별도 임시 데이터로 준비하며 QA 계정명·실제 개인 정보를 홍보 자산에 포함하지 않는다.
- 이름·역할·팀 배치가 읽히도록 편성 영역을 중심으로 크롭한다. 새로 그린 그림을 실제 제품 화면처럼 제시하지 않는다.
- 모바일은 전용 크롭을 검토한다. 명단과 두 팀을 함께 읽기 어렵다면 두 팀을 대표 이미지로 두고 참가자 목록은 다음 설명 구간에서 보여준다.
- `내전 편성 · 예시 화면` 캡션과 대체 텍스트를 제공한다. 필요한 설명은 이미지 밖에도 쓴다.
- 자동 슬라이드·자동재생·실제 앱 임베드는 사용하지 않는다. 테마별 촬영본이 없으면 고정 프레임 속 예시로 표현하며 색을 강제로 반전하지 않는다.

## 6. 이용 안내와 이동

지원 게임은 이름·실제 제공 상태를 간단히 표시한다. QA 활성 상태만으로 운영 제공 상태를 단정하지 않는다. `회원가입은 무료입니다.`를 제안하며 무료 기능 범위는 실제 Free/Premium 정책을 확인한 뒤 작성한다. Premium은 필요하면 `Premium 구독 결제는 준비 중입니다.` 한 줄로 표시하고 큰 가격표·구매 버튼은 제외한다. 이용자 수·후기·효과 수치를 만들어 넣지 않는다.

| 상태 | 시작 행동과 목적지 |
| --- | --- |
| 비로그인 | 무료로 시작하기 → `/sign-up`, 로그인 → `/sign-in` |
| 로그인한 `/` 직진입 | 기존 `/games` 자동 이동 유지 |
| 로그인한 `/?from=logo` | 가입 버튼 대신 게임 선택으로 → `/games`. 기존 계정 메뉴 유지 |
| 세션 확인 실패 | 개인 정보를 추측하지 않고 시작하기 → `/games`의 인증 가드에서 재확인 |

로고 재방문·기존 인증 규칙은 유지한다. 정책 링크는 실제 존재하는 경로만 제공한다. 게스트를 보호된 편성 화면으로 바로 보내지 않는다.

## 7. 범위·실패 상태·완료 기준

기획에 이어 개발 전용 시안에서 구도와 하단 섹션을 검토한다. 공개 랜딩·DB·가입 흐름·편성 알고리즘·운영 배포는 변경하지 않는다. 신규 데이터 집계 서비스도 추가하지 않는다.

| 진입·상태 | 처리 계획 |
| --- | --- |
| 대표 이미지 지연·실패 | 비율·캡션 공간 유지. 프레임 안에 `화면 예시를 불러오지 못했습니다.` 표시 |
| 지원 상태 조회 실패 | 영역 안에 `지원 정보를 불러오지 못했습니다.`와 재시도 제공. 실패를 미지원으로 표시하지 않음 |
| 화면 보기 앵커 | 대표 화면으로 이동. 키보드 초점·모션 감소 설정 처리 |
| 시작 버튼 | 로그인 상태에 맞는 실제 경로로 이동. 모의 가입 완료·체험 상태를 만들지 않음 |

구현 후 확인할 기준:

1. 첫 화면에서 대상·핵심 가치·시작 행동을 이해할 수 있는지 사용자 검토를 받는다.
2. 320/390/768/1024/1280px에서 제목·버튼·대표 화면이 겹치거나 가로로 넘치지 않는다.
3. 비로그인·로그인 직접 진입·로고 재방문의 목적지가 위 표와 일치한다.
4. 키보드·테마·모션 감소·이미지 실패·지원 상태 실패에서도 읽기 순서와 영역 크기를 유지한다.
5. 예시 화면과 설명이 현재 기능·실제 이용 범위와 일치한다.

### 2026-10-30 하단 섹션 시안

- 사용자가 중앙형 구도를 승인했다. 그 아래에 참가자 확인 → 편성 결과와 팀 조정 → 경기 기록 → 이용 안내 → 시작 버튼을 연결한다. PC의 기능 설명 두 행은 좌우 교대, 모바일은 설명 다음 화면 순서다.

### 2026-10-30 클랜 활동·통계 추가

- 숫자는 서비스 실적이 아닌 가상의 예시임을 명시한다. 기존 QA 데이터·공개 랜딩·운영 배포는 유지한다. [검증](../../TODO_Phase2.md#2026-10-30-랜딩-클랜-활동통계-시안).

### 2026-10-30 영역별 페이지네이션

- 사용자 지정 영역에 한해 내전 준비(참가자·팀 비교), 기록과 통계(경기 기록·월별 추이·맵별 경기·개인 성적), 클랜 활동(홈·게시판·사진·알림·이벤트)의 세 독립 페이지네이션을 적용한다. 대표 편성 화면과 클랜 활동 오른쪽 설명은 유지하며 별도 통계 행은 기록 영역에 합친다.
- 점·이전/다음 버튼과 현재 페이지 이름·번호를 제공한다. 자동 전환 없이 방향키·Home/End로 선택하고 비활성 패널은 접근성과 초점에서 제외한다. 전환 시 높이와 각 내부 화면 상태를 유지하며 긴 기록·클랜 화면은 내부 스크롤을 사용한다.
- 실제 컴포넌트에 로컬 가상 데이터를 전달한다. 사진은 번들 맵 이미지로 구성한 예시임을 표시하고 알림은 실제 전송·조회 없는 내용 예시로 구별한다. [검증](../../TODO_Phase2.md#2026-10-30-랜딩-영역별-페이지네이션).

### 2026-10-30 통계의 정보량과 압축 기준

- 사용자가 실제 통계의 풍부함과 스크롤 없는 미리보기를 요청했다. 통계를 명예의 전당 / 클랜 통계 / 경기 기록 / 개인 기록 / 맵과 시너지의 5장으로 구성한다. 설명은 짧게 두되 순위·반응, 세 종류의 분포, 프로필·엠블럼, 역할·맵·멤버별 성적을 살린다.
- 위의 내부 스크롤 방식을 폐기한다. 자연 높이로 모든 슬라이드의 공간을 예약하고 긴 목록은 대표 행으로, 모바일 그래프는 필요한 경우 표 중심으로 압축한다. 콘텐츠를 고정 높이로 잘라 스크롤바만 숨기거나 화면 전체를 축소하지 않는다.
- 순위·기록·프로필·시너지는 로컬 예시를 사용한 압축 표현으로 구별한다. 도넛·역할 아이콘·엠블럼은 기존 서비스 컴포넌트와 자산을 재사용한다. 실제 개인정보·QA DB 조회·알림 전송·업로드는 없다. [검증](../../TODO_Phase2.md#2026-10-30-랜딩-통계-확장과-스크롤-제거).

### 2026-10-30 편성 방식과 관전자 재미를 우선 소개

- 사용자 피드백에 따라 참가자 명단·팀 비교 소개를 제거하고 네 가지 편성 방식과 승부 예측을 중심으로 바꾼다. 설명은 항상 노출하며 우측 경매·예측 두 장만 점 페이지네이션으로 전환한다. 작은 화면은 설명 아래 미리보기를 배치하며 내부 스크롤을 만들지 않는다.
- 주장 지명은 차례로 팀원 선택, 팀원 경매는 크레딧 입찰, 역할별 추첨은 역할을 유지한 팀 추첨, 자동 배정은 선호 역할·추첨 순서에 따른 역할 배정으로 설명한다. 자동 배정을 평가 점수 기반의 최적 팀 보장으로 표현하지 않는다.
- 경매·예측은 기능을 압축한 정적 예시다. 실제 입찰·코인 참여 버튼 대신 현황을 보여주고 가상 데이터임을 명시한다. [검증](../../TODO_Phase2.md#2026-10-30-랜딩-편성-모드와-승부-예측-소개).


### 실제 UI 재사용 기준 (2026-10-30)

- 압축하더라도 실제 UI의 형태와 구성은 유지한다. 경매·승부 예측·순위·기록·개인 통계·프로필·엠블럼·알림을 별도 디자인으로 재구현하지 않고 서비스의 표시 컴포넌트를 공유한다. 위 압축 표현 단계의 대체 화면은 이 기준으로 교체했다.
- 실제 조회·입찰·예측·댓글·읽음 처리는 연결하지 않는다. 데이터가 필요한 컨트롤러와 표시 부분을 분리하고 예시 데이터만 전달한다. 원래 서비스 경로의 동작은 그대로 둔다.
- 목록은 대표 항목으로 줄이고 여백·카드 높이를 조정한다. 내부 스크롤이나 화면 전체 축소 대신 읽을 수 있는 크기를 유지한다. 외부 페이지네이션과 중앙형 히어로는 유지한다. [검증](../../TODO_Phase2.md#2026-10-30-랜딩-실제-ui-재사용).


### 대표 장면과 공통 규격 (2026-10-30)

- 최신 사용자 피드백에 따라 내전은 편성 → 영웅 밴 → 승부 예측, 기록은 클랜 통계 일부 → 경기 기록 일부 → 개인 기록 일부, 활동은 사진 → 일정 → 알림 순서로 각 3장만 제공한다.
- 실제 UI 전체를 넣지 않고 대표 영역만 선택한다. 긴 설명 목록을 제거하고 각 장면에 제목과 한 문장만 둔다. 프레임은 고정 높이 대신 실제 UI의 자연 높이와 상하 12px 여백을 사용한다. 같은 구간의 세 장은 가장 높은 콘텐츠에 맞춰 높이를 유지하며 내부 스크롤 없이 표시한다. 모바일에서는 클랜 통계의 맵별 경기만 대표로 제공한다. 중앙형 히어로는 유지한다.


### 좌우 설명 배치 (2026-10-30)

- 내전은 설명 왼쪽·UI 오른쪽, 기록은 UI 왼쪽·설명 오른쪽, 활동은 설명 왼쪽·UI 오른쪽으로 배치한다. 900px 이하에서는 설명 위·UI 아래로 쌓는다. UI 프레임은 콘텐츠 높이를 사용하고 페이지 전환 영역은 구간 내 최대 높이를 유지한다.
- 영웅 밴은 실제 결과 카드의 초상화를 크게 표시하고, 승부 예측은 실제 코인 입력·참여 버튼까지 보여준다. 모두 로컬 예시·읽기 전용이다. 좁아진 데스크톱 통계 미리보기는 맵별 경기·영웅 밴 두 장의 카드를 대표로 사용해 이름 잘림을 방지한다.

### 시각 위계와 탐색 마감 (2026-10-30)

- 중앙형 히어로·좌우 배치·실제 UI를 유지하며 제목의 굵기와 색상 위계, 얇은 프레임과 그림자, 구간 간격을 통일한다. 사진은 기존 사진 UI를 앨범처럼 배치한다. 라이트·다크는 기존 테마 토큰을 따른다.
- 데스크톱 상단에 내전 기능·기록과 통계·클랜 활동 앵커를 추가한다. 페이지네이션은 점과 기능 이름을 함께 노출하고 중복된 현재 이름·번호는 화면 읽기 도구의 알림으로만 유지한다. 키보드 이동·상태·구간 높이는 유지하며 전환 효과는 모션 감소 설정을 존중한다.

### 경기 기록의 당일 통계 복원 (2026-10-30)

- 경기 기록 미리보기는 실제 경기 카드와 `ArchiveDayTable`을 함께 표시한다. 표는 이름·승/무/패·승률을 대표 열로 사용하며, 640px 이하에서는 경기 카드 아래에 정렬 결과의 대표 3명만 표시한다. 날짜 필터·내전 요약은 계속 생략한다.
- 실제 레이아웃의 두 열을 만드는 그리드에 직접 미리보기 규칙을 적용한다. 숨겨진 표 자리가 빈 열로 남지 않으며, 내부 스크롤 없이 경기 이동·당일 전체 집계·표 정렬을 유지한다.
