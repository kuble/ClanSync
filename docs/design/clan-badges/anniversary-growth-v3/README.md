## 케이스와 상세

- 전체/기념 케이스에는 달성한 가장 높은 주년 **한 슬롯**을 표시한다. 5주년까지 달성했다면 5주년만 진열하며, 첫 주년 전에는 1주년 빈 홈 하나를 표시한다.
- 주년을 선택하면 상세 창을 연다. 데스크톱 상단 왼쪽은 큰 배지 이미지, 오른쪽은 이름·이야기·획득 방식·획득일/예정일이다. 그 아래 같은 안감의 연관 케이스에 1·3·5·10주년을 모두 표시한다. 모바일은 이미지·설명·케이스를 세로로 배치한다.
- 연관 배지를 선택하면 상단 이미지와 설명을 함께 바꾼다. 미획득은 빈 홈이며 상단 그림은 회색 미리보기와 명확한 미획득 표시를 사용한다. 이전 단계를 선택해도 바깥 케이스의 최고 단계는 바뀌지 않는다.
- 운영 현황/대시보드의 대표 진열도 주년 계열을 한 슬롯으로 합친다. 이전 주년을 대표로 저장했다면 현재 최고 주년으로 표시하고 중복 주년 슬롯을 제거한다. 대표 저장/해제 시 현재 최고 키로 저장하며 이전 단계는 별도 대표로 지정하지 않는다.
- 기존 주년별 획득 기록·기준일·UTC 윤일 계산·권한을 유지한다. 주년 기록을 병합하거나 삭제하지 않으며 DB 스키마 변경은 없다.
- 후속 사용자 요청으로 **모든 단계형 계열**에 같은 표시 방식을 적용한다. 멤버·정규·깜짝 내전도 최고 달성 한 슬롯과 전체 단계 상세를 사용한다. 향후 계열은 카탈로그의 `series`와 `target` 또는 `years`를 지정하면 같은 구조로 진열한다.

## 제작 기록

내장 `image_gen.imagegen`으로 한 잎 1주년과 무성한 10주년을 편집했다. 3주년은 V2의 세 잎, 5주년은 V2의 다섯 잎 원본을 변경 없이 복사했다. 네 파일 모두 1254 × 1254px RGBA이며 원본 해시 일치·투명 모서리를 확인했다. 전체 편집 요청과 재사용 원본은 [prompts.json](prompts.json)에 보관한다. [이전 V2](../anniversary-growth-v2/README.md)는 제작 이력으로 보존한다.

관련 검증은 [단계·상세 E2E](../../../../e2e/clan-badge-series.spec.ts), [멤버·회수 E2E](../../../../e2e/clan-badge-growth.spec.ts), [운영 현황·대표 진열 E2E](../../../../e2e/clan-management-overview.spec.ts)를 사용하며 결과는 [Phase 2](../../../TODO_Phase2.md)에 기록한다.
