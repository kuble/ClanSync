# S04 — 밸런스메이커

## 결정 참조

- **세션·라운드·내전 날짜·회차(`D-SESSION-01`, 2026-09-16 확정):** [내전 운영 용어](../glossary.md#내전-운영-용어). 세션은 당일 내전 전체, 라운드는 경기 한 판이며 실제 앱·DB 반영 여부와 구분한다.
- 네임플레이트·경기 슬롯 동기화 **[D-PROFILE-01](../decisions.md#d-profile-01--네임플레이트-동기화-규약)** · Premium 잠금 동선 **[D-STORE-02](../decisions.md#d-store-02--premium-잠금-카드의-업그레이드-안내-동선)** · 스크림 확정 후 이벤트 자동 생성 **[D-EVENTS-01](../decisions.md#d-events-01--스크림-확정--클랜-이벤트-자동-생성동기화)**.
- 운영 권한·세션 내 액션은 전역 매트릭스 **[D-PERM-01](../decisions.md#d-perm-01--클랜-권한-매트릭스-모델-도입)** 와 정합. 세부 카피·플로우는 [pages/09-BalanceMaker.md](../pages/09-BalanceMaker.md) 단일 출처.

## 스코프

- 운영진이 세션을 열면 클랜원이 사이트에서 세션에 접근하여 실시간 참여한다. 조작·밴픽·베팅은 역할·라운드 출전 여부·기능 권한·플랜에 따라 제공한다. 세션 접근이 배치 편집이나 모든 베팅 권한을 뜻하지 않는다.
- 내전 날짜는 **세션 개설 시점의 KST 날짜**로 고정한다. 같은 세션에서 라운드를 반복하고, 종료 시점까지 진행한 라운드를 해당 내전의 회차로 기록한다. 기존 KST 06:00 일일 집계 기준은 내전 날짜·세션 분할 기준과 별개다. 경기 진행 중에는 결과 기록 후 종료하며 편집 중 라운드는 무효 기록으로 닫는다. 다음 라운드는 회차를 증가시키고 닫힌 세션 재개는 후속이다.
- 주장 지명·경매의 역할 선고정 확정(2026-09-16). QA에 적용한 방식·저장 규칙·공유 연출과 지명 시간 제한 등의 후속 제안은 [편성 명세](../../02-design/formation-modes.md)에서 구분한다.
- 기본 명단 입력은 최근 참여순 클랜원 목록에서 운영진이 직접 선택(2026-09-16 사용자 확정·기존 정렬 설계 확인). 출전자 10명 유지·라운드 사이 교체라는 기존 운영 방식에 맞춰 [D-UX-01 논의](../product-design-evolution.md#ux-01)에서 수동 UI/UX를 확정했다. 실제 적용·검증 현황은 [Phase 2](../../TODO_Phase2.md)의 2026-09-16 기록을 따른다.
- 확정한 수동 명단은 **라운드 출전자 10명**을 위한 좌우 5칸이며, 각 팀 **딜·딜·탱·힐·힐** 고정과 중앙 역할 아이콘을 사용한다. 출전 명단의 관전자 등록만 제외하며 세션 접근 인원을 10명으로 제한하지 않는다. 이름 클릭 → 고정 순서 첫 빈칸 입력, 자리 우클릭 → 비우기, 위 명단 드래그 → 빈칸 이동/두 사람 교환. 선택자는 하단 후보에서 숨기고 명단에서 빼면 기존 정렬 위치에 돌려놓는다. 되돌리기·리셋은 참여자 영역 우상단 아이콘으로 두며 리셋도 한 번에 복구한다. 별도 자리 선택·교환 모드·반복 위치 문구·체크·색상 범례·복구 완료 문구는 제거한다. 변경 자동 저장·편성 전 저장 완료 대기·충돌 시 변경 보관을 실제 앱에 적용했다.
- 역할 선호는 게임별 프로필 기본값 또는 본인의 이번 라운드 입력을 사용한다. 입력 없는 사람도 남은 역할 자리에서 추첨하며 체크인은 요구하지 않는다. 순위는 본인만 조회하고 서버가 편성 시 해석한다.
- 라운드 설정은 역할/팀 방식·주장·경매 규칙·밴픽을 저장하고 다음 라운드에 재사용한다. 개인 라운드 선호·주장 지정·추첨 이력은 새 라운드로 복사하지 않는다. 실제 허용 범위는 [편성 명세](../../02-design/formation-modes.md)를 따른다.
- 저장 결과를 약 4초에 기존 참가자 보드에서 공개하며 직접 배정+팀 유지에는 가짜 추첨을 넣지 않는다. 다시 보기·중복 결과 명단·상시 안내는 두지 않고 도움말 오버레이와 최근 30세션 기록 drawer는 아이콘으로 연다.
- 대기방 화면 연결은 프로젝트 적용 방향 확정(2026-09-16). OCR 명단 후보와 수동 선택의 합류를 구현 대상으로 포함한다. 게임사 문의는 후속이며 실제 구현·검증은 미완료다. 플랜 범위·세부 UX는 미결이다.
- 세션 개설 → 라운드별 배치 편집·완료 → 밴픽 → 라운드 시작·결과 확정 → 다음 라운드 또는 세션 종료. 배치 편집은 기존 내전 운영 권한(`manage_clan_events`)을 따르며 주장에게는 자기 팀 지명·입찰만 허용한다.
- 수동(M)·자동(A) 점수 표기: **Premium**에서만 A 관련 UI (Free는 M 고정 등)
- 라운드별 승부예측 마감·결과 노출, Premium: 자동 밸런스·OCR·디스코드 알림(선택). 승부예측은 해당 라운드 비출전 구성원에게만 제공한다.
- 라운드 슬롯 네임플레이트(프리셋만)
