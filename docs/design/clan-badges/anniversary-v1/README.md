# 주년 배지 디자인 후보

제작일: 2026-10-14 · 상태: **4번 자라는 역사 선택 이력 — 현재는 [성장형 V3](../anniversary-growth-v3/README.md) 적용**

## 초기 시안 비교 기준

기본 디자인 후보는 5개이며, 각 비교 이미지에는 동일한 문양과 형태의 배지 4개가 왼쪽부터 나란히 배치되어 있다.

| 주년 | 테두리 금속 | 표현 |
|---|---|---|
| 1주년 | 동 | 따뜻한 구릿빛, 브론즈 |
| 3주년 | 은 | 차분한 중성 회색, 브러시드 실버 |
| 5주년 | 금 | 밝은 금빛, 폴리시드 골드 |
| 10주년 | 플래티넘 | 밝은 은백색과 옅은 푸른 반사 |

후보 안에서 중심 문양, 에나멜 색, 내부 금속 선과 장식 수는 유지하고 바깥 테두리 금속으로 연차를 구분한다. 기존에 선택한 [첫 깃발](../../../../public/clan-badges/founding-first-banner.png)의 에메랄드·민트·아이보리 에나멜과 입체 금속 질감을 공통 제작 기준으로 사용했다. 주년 표기는 배지 밖에 둔다.

## 기본 디자인 5종

| 번호 | 디자인 | 의미 |
|---|---|---|
| 1 | [사계의 인장](01-seasons-seal.png) | 한 해의 사계절을 함께 지나온 기록 |
| 2 | [함께한 시간](02-shared-hours.png) | 쌓여온 시간과 앞으로 이어질 시간 |
| 3 | [영원의 매듭](03-eternal-knot.png) | 클랜을 이어주는 끊어지지 않는 인연 |
| 4 | [자라는 역사](04-growing-history.png) | 같은 뿌리에서 더 단단해지는 클랜의 역사 |
| 5 | [이어지는 빛](05-lasting-star.png) | 첫 깃발의 별이 시간이 지나도 이어지는 기념 |

사용자는 4번 **자라는 역사**를 선택했다. 초기 구현은 다섯 잎·금빛 줄기와 뿌리·작은 별·아이보리 바탕을 유지하고 테두리만 연차별 금속으로 변경했다. 후속 선택으로 현재는 잎·줄기·뿌리가 자라는 V2를 사용한다.

## 초기 개별 원본 — 성장형 V2로 대체

| 주년 | 적용 원본 |
|---|---|
| 1주년 · 동 | [bronze PNG](../../../../public/clan-badges/anniversary-growing-history-bronze.png) |
| 3주년 · 은 | [silver PNG](../../../../public/clan-badges/anniversary-growing-history-silver.png) |
| 5주년 · 금 | [gold PNG](../../../../public/clan-badges/anniversary-growing-history-gold.png) |
| 10주년 · 블랙 루테늄 | [black ruthenium PNG](../../../../public/clan-badges/anniversary-growing-history-black-ruthenium.png) |

동 배지를 비교 시안에서 투명 배경으로 분리한 뒤 그 원본의 테두리를 편집해 은·금·플래티넘 3종을 제작했다. 내장 `image_gen.imagegen`을 사용했으며 전체 제작 요청은 [production-prompts.json](production-prompts.json)에 보관했다. 각 PNG는 1254 × 1254px RGBA이며 생성 원본의 알파를 유지해 복사했다.

10주년 테두리는 후속 요청으로 [마감 후보 3종](metal-alternatives-v1/README.md)을 비교한 뒤 **3번 블랙 루테늄**으로 확정·교체했다. 이후 성장형 V2에서는 첫 깃발·성채와 같은 금빛 테두리로 다시 통일했다. 초기 개별 원본·플래티넘 원본과 제작 요청은 비교 이력으로 보존한다.

## 원본과 검증

- 내장 `image_gen.imagegen`으로 디자인별 비교 이미지 1장씩, 총 5장을 생성했다. 기존 첫 깃발 PNG는 제작 질감 참고로만 전달했다.
- 각 PNG는 1942 × 809px의 비교용 이미지이며, 4개 배지·주년 표기·테두리 금속 차이와 기본 문양의 일관성을 육안으로 확인했다.
- 파일은 생성 원본을 수정 없이 복사했다. 재생성용 전체 요청은 [prompts.json](prompts.json)에 보관했다.
- 선택한 개별 PNG와 공통 방패 실루엣을 전체 케이스·대표 진열에 적용했다. 창단일의 1·3·5·10년 기준일에 획득하며 기존 1주년 키/발급 기록은 유지한다. DB 스키마는 변경하지 않았다.
