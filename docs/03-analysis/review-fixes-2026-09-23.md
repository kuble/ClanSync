결과: **fixed (현재 브랜치·QA 환경)**. 원 검토의 보안 7건과 기능 오류 8건을 수정했다. 경매 버튼의 증감 단위도 설정값에 맞췄다. 운영 DB·운영 배포는 적용하지 않았다.

## 보안 경계

| 문제 | 수정과 재현 검증 |
|---|---|
| 저장된 알림 URL을 통한 서버 요청 | 정확한 HTTPS Discord 호스트·웹훅 경로만 허용한다. 수동 일정/투표 배치의 공통 발송 함수에서 재검사하고 리디렉션을 거부한다. 내부 주소·위장 호스트·경로 우회는 거절되며 정상 주소의 전송 옵션은 유지된다. |
| 일반 멤버의 웹훅 비밀 조회 | 기존 URL을 서비스 전용 `clan_notification_secrets`로 옮기고 공유 JSON에서 제거했다. 공유 컬럼에 URL 재삽입도 차단한다. 클랜장의 저장·빈 입력 유지·해제를 검증했고 일반 사용자와 클랜장의 직접 비밀 SELECT는 거절된다. 클라이언트에는 설정 여부만 전달한다. |
| 다른 게임의 부계정 조회 | 공통 클랜과 부계정의 game_id를 연결했다. 본인의 두 게임 계정은 모두 보이고 공유 클랜의 게임만 동료에게 보이는 것을 확인했다. |
| 단일 선택 투표 동시 제출 | 부모 투표 잠금 후 기존 선택 삭제·새 선택 저장을 한 RPC에서 처리한다. 서로 다른 선택지의 동시 최초 요청을 반복해도 한 표만 남는다. 복수 선택·변경·종료 후 거부도 확인했다. |
| 예측 변경과 정산 경합 | 예측 INSERT/UPDATE가 정산과 같은 라운드를 먼저 잠그며, 대기 후 경기 상태·마감·본인 여부를 재검사한다. 기존 적중자가 있는 상태에서 예측 변경과 정산을 5회 경합시켜 클랜 차감과 개인 지급 합계가 일치했다. 이후 변경과 예측 소유권 변경은 차단된다. |
| 로그인 외부 이동 | 네 경로가 공통 반환 경로 검증기를 사용한다. 백슬래시·제어문자·인코딩 변형·외부 호스트는 거절하고 정상 내부 경로/쿼리/해시는 유지한다. |
| 제한된 내전 기록 직접 조회 | DB에서도 운영진 또는 본인이 연 열린 깜짝 방의 기록만 허용한다. 일반 멤버의 현재 라운드는 유지한다. 종료된 정규 기록과 다른 멤버의 깜짝 기록은 조회되지 않는다. 대시보드/통계는 멤버 확인 후 서버에서 집계하여 경기 수를 보존하고 권한 없는 원시 기록은 반환하지 않는다. |

## 기능·호환성

- 반복 일정은 서버 시간대와 관계없이 한국 시간의 시작 시각으로 계산한다. 기존 UTC 방식으로 저장한 repeat_time도 시작 시각 기준으로 읽는다. UTC/KST/미국 시간대, 월말·월간 반복·초 단위 첫 회차를 검증했다. 독립 재검토에서 발견한 달력 월 경계 회귀는 인접 한국 월을 포함하는 브라우저 달력용 계산으로 수정하고 UTC 브라우저에서 월말 일정 선택까지 확인했다.
- `forbidden()` 설정과 접근 거부 화면을 추가했다. 일반 멤버의 관리 화면 접근이 E488 대신 안내 화면을 반환한다.
- 스크림은 예정 일정과 최근 과거 일정을 따로 조회해 오래된 48건 때문에 새 일정이 숨지 않는다. 양측 동시 확인은 부모 방 잠금으로 직렬화하며 확정 상태와 일정 2건을 확인했다.
- 맵/영웅 밴 결과는 라운드 잠금 뒤 마감된 투표를 읽는다. 먼저 접수된 투표가 끝나기를 기다리고, 늦은 표·다른 마감 식별자·권한 없는 집계는 거부한다. 결과 저장의 기존 버전 검사는 유지한다.
- 같은 반복 예약에서 열린 방이 여러 개여도 각 방이 로비에 남는다.
- `edit_mscore` 위임을 받은 멤버는 점수 전용 RPC로 저장한다. ±10, 출전자 제한, 권한 회수 및 다른 경기 필드 변경 차단을 확인했다.
- 모집 신청 수는 별도 집계로 제공해 신청자/작성자에게 같은 수를 보여 준다. 다른 신청자의 상세 정보는 기존 접근 제한을 유지한다.
- 경매 증감 버튼은 최소 입찰 단위의 1배/10배로 작동한다. 기본 10pt 설정의 ±10/±100 표시는 유지한다.
