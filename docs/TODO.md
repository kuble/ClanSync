# 현재 작업

**현재 초점: 밸런스메이커의 명단 자동 저장·개인 선호·설정·공유 연출·기록 화면을 QA에서 확인한다.**

**사용자 지시(2026-09-16): QA에서 먼저 테스트.** 운영 DB 마이그레이션·운영 배포는 보류한다. 작업 브랜치는 `codex/live-session-formation`이다. QA는 마이그레이션 56개, 운영은 기존 50개이며 main 반영 전에 운영 적용이 필요한 마이그레이션은 6개다. QA 서버는 `npm run dev:qa`(3011), 현재 열린 명단은 사용자 테스트 중이므로 시드 재실행으로 초기화하지 않는다. 새 내전 E2E는 별도 12명·임시 클랜으로 실행한다.

**공통 기준 확정(2026-09-16, D-SESSION-01):** 세션은 당일 내전 전체, 라운드는 경기 한 판. 열린 세션에 클랜원이 사이트로 실시간 참여하고 권한에 따라 조작·베팅한다. 내전 날짜는 세션 개설일로 고정하며 종료 시점까지 라운드·회차를 기록한다. [용어 사전](01-plan/glossary.md#내전-운영-용어)에 정리했고 실제 앱·DB에 반영했다. 검증 범위는 [Phase 2 현황](TODO_Phase2.md)을 따른다.

마지막 갱신: 2026-09-16 — [고도화 논의 문서](01-plan/product-design-evolution.md)의 `D-UX-01` 중 **수동 명단 입력 UI/UX 확정.** 고정 역할·순서 자동 입력·우클릭 삭제·선택자 숨김·참여자 드래그 이동/교환·우상단 되돌리기/리셋 아이콘을 기준으로 삼는다. 실제 앱에 명단 자동 저장, 편성 전 저장 완료 대기, 동시 편집 충돌 처리와 터치/키보드 보조 입력을 반영했다. 도움말은 요청할 때만 열고, 확정 결과는 기존 참가자 보드에 표시한다. 대기방 연결 적용 방향은 확정, 게임사 문의·OCR 구현은 후속이다.

**편성·화면 적용 범위:** `D-UX-03`의 **역할 선확정 → 팀원 선발**을 유지한다. 프로필의 게임별 선호와 본인의 이번 라운드 선호를 자동 반영하고, 설정에 역할/팀 편성 방식·주장·경매 규칙·밴픽을 모았다. 설정은 다음 라운드에도 이어지며 라운드 선호와 주장 지정은 새로 시작한다. 저장한 결과를 약 4초에 공개하고 다시 보기·체크인은 두지 않는다. 기록 drawer에서 최근 30세션의 날짜·라운드·승패 통계·공개 추첨 이력을 조회한다. 불가 역할·실력 자동 균형·지명 시간 제한·자동 경매 마감·다팀 대회는 후속이며 [편성 명세](02-design/formation-modes.md)를 따른다.

**이번 검증:** 역할/편성 로직 14건·자동 저장 8건·기록 6건, QA DB 전체 44건 및 SQL 린트·빌드·타입·src 린트 통과. 전체 회귀 82건 통과 후 수정한 내전 통합 1건과 프로필 1건 개별 재검증 통과, 총 84시나리오. 실시간 구독 초기 누락 복구, 설정 적용 직후 시작 경합, 오래된 재추첨 요청과 프로필 저장 후 불필요한 화면 갱신을 보완했다. 상세 범위는 [Phase 2 현황](TODO_Phase2.md)을 따른다.

목업 기준 개편과 로그인·페이지 이동 성능 개선은 운영 반영 완료. Phase 2 전체 종료 감사(M8)는 별도다.

기존 구현 검증(2026-09-15): 브라우저/로직 회귀 43건·빌드·타입·src 린트 확인. 페이지 서버 서울 배치 후 운영 3회 중앙값: 로그인 8.2→1.9초, 관리 10.6→1.4초. Vercel production READY. DB는 기존 마이그레이션 50개·테스트 24개 검증 상태를 유지한다.
