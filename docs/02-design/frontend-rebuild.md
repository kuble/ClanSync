## 검증 원칙

- 목업과 앱을 같은 화면 크기에서 비교한다. 색상 변경만으로 완료 처리하지 않는다.
- 기본·데이터 없음·로딩·오류·권한 없음 및 Free/Premium 조건을 확인한다.
- QA DB `moretvteewfcztxvwztw`만 시드·업무 동작 테스트에 사용한다. 운영에 QA 데이터를 추가하지 않는다.
- 테스트 셀렉터를 임의로 무효화하지 않는다. 변경된 사용자 흐름에 맞는 의미 있는 검증만 보강한다.
- 전체 코드가 준비된 단위마다 lint/build/E2E 후 커밋·푸시, 운영 자동 배포를 확인한다.

## 사용량과 중단 시 재개

- 시작 시 주간 잔여 15%, 리셋 크레딧 3개. 사용자가 **잔여 1% 이하가 되었을 때 크레딧 1개 사용**을 명시 승인했다. 1%를 초과하면 사용하지 않는다.
- 크레딧 사용은 승인된 1개에만 한정한다. 추가 크레딧은 새 승인이 필요하다.

- 의미 단위 커밋과 이 파일의 상태를 수시로 갱신한다. 중단돼도 이미 검증한 기능을 재작성하지 않는다.

### 기존 서버 기능의 미구현 범위

- 실제 게임 OAuth 및 유료 결제는 별도 범위. 운영 UI에서는 준비 상태 표시.
- 자동 팀 편성/OCR·A 자동 산정·수동 맵 선택/맵 분류·호스트 단독 편집·당일 전적, 대진표 실제 진출/정산은 기존 서버에 미구현. 기능을 임의 수치로 대신하지 않는다.
- 공개 커뮤니티 순위는 최근 활동 기준이며 월별 경기 수·개인 공개 순위·인사이트 집계는 미구현.
- 스토어 판매 가능 실제 상품은 클랜 배너 슬롯/프로필 프레임 2종. 목업 샘플 카탈로그는 판매 상품으로 허위 노출하지 않는다.
- 개편 당시에는 06시 게임일 경계가 미결이라 기존 KST 자정 집계를 유지했다. **후속 확정(2026-09-16, D-SESSION-01): 내전 날짜는 세션 개설일로 고정하고 종료까지의 라운드·회차를 그 세션에 기록한다.** 별도 통계 집계 기준과 구분한다([용어 기준](../01-plan/glossary.md#내전-운영-용어)). 최신 정의의 앱·DB 반영 여부는 별도 대조·검증이 필요하다.
