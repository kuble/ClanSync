# 게임 에셋 권리 확인·문의 목록

기준일: 2026-09-26. 상태: **사용 허락 확인 전 / 문의 미발송**.

게임사 문의에 첨부할 개발 자산 목록이다. 아래 우선순위는 원본 게임 이미지 사용, 제3자 경유, 유사 도안 재작성, 허락 근거 부재를 기준으로 정했다. 법적 침해 여부나 발생 확률을 확정한 표가 아니다. 사용자는 권리 문의를 후속으로 진행하기로 했으며, 이번 작업은 조사·문서화까지다.

## 1. 문의 대상과 서비스 설명

- **Nexon:** `sht-vod.dn.nexoncdn.co.kr`에서 제공되는 영웅 초상화 11개. 외부 서비스 표시·직접 링크·캐시·재가공 허용 범위 및 Nexon이 안내할 수 있는 권리 범위를 질문한다.
- **Blizzard Entertainment:** 오버워치 게임 화면·캐릭터·역할/모드 도안의 원본 권리 확인 대상. Nexon 또는 제3자 서버에서 제공된다는 사실만으로 원본 권리의 허락이 확인된 것은 아니다.
- **OverFast:** 경유한 맵 이미지 13개에 대해 배포 출처와 사용 조건을 확인한다. API/코드 라이선스와 게임 이미지 이용 허락은 구분한다.
- 문의 시 ClanSync를 독립적인 클랜 운영 웹서비스로 설명한다. 내전 편성·통계·맵 선택·영웅 밴에 에셋을 표시하며 Free/Premium 구조가 있다. 현재 실제 유료 결제 연결은 후속 상태다. 공개·유료 기능·광고·프로모션 사용 범위를 각각 설명한다.

6 + 11 + 42 + 13 + 17 + 3 = **정적 파일·고정 URL 92개**. 개별 경로·원본 URL은 [문의 첨부용 CSV](game-assets-inventory.csv)에 수록한다. 파일 또는 URL이 존재한다는 것과 실제 모든 화면에서 노출된다는 것은 구분한다.

### Nexon CDN 11개 키

`dmon`, `domina`, `hazard`, `anran`, `emre`, `sierra`, `shion`, `vendetta`, `jetpack_cat`, `mizuki`, `wuyang`.

### 맵 유형 첨부물의 취급

사용자는 나무위키 오버워치/전장 문서에서 복사한 이미지라고 설명했다. 해당 페이지의 원본 저자·이미지 라이선스는 확인되지 않았다. 원본 PNG를 저장소에 포함하지 않고 SVG를 직접 재작성했으나, 원본 도안을 참고했다는 출처를 남긴다. 로컬 클립보드 경로는 문의 상대에게 불필요하므로 첨부 CSV에 기록하지 않는다.

## 3. 사용 화면과 재현 위치

| 화면 | 상대 경로 | 확인할 에셋 |
|---|---|---|
| 내전 팀 편성 | `/games/overwatch/clan/{clanId}/balance?room={roomId}` | 팀 사이 역할 아이콘 |
| 경기 준비 / 맵 선택 | 위 내전 화면의 맵 단계 | 모드 아이콘+이름, 개별 맵 카드 이미지. 유형 대표 배경 이미지는 이번 UI 수정에서 제거 |
| 영웅 밴 | 위 내전 화면의 밴 단계 | 영웅 초상화 |
| 내전 통계 | `/games/overwatch/clan/{clanId}/stats` → 내전 통계 | 맵·영웅 도넛/썸네일, 역할·모드 필터 |
| 개인 기록 | 위 통계 → 개인 기록 | 역할 필터/조합표, 맵별 도넛 |

문의에 화면 캡처를 추가할 때 QA용 가상 닉네임을 사용하고 계정 이메일·쿠키·인증 정보·DB 키는 포함하지 않는다.

## 4. 문의 초안

제목: 오버워치 클랜 운영 웹서비스 내 게임 이미지·아이콘 사용 범위 문의

안녕하세요. 독립 클랜 운영 서비스 ClanSync를 개발 중입니다. 내전 편성, 맵 선택, 영웅 밴, 경기 통계에서 게임 식별을 위해 첨부 목록의 이미지를 사용하고자 합니다. 서비스에는 Free/Premium 구분이 있으며 실제 유료 결제 연결은 후속으로 계획하고 있습니다.

1. 첨부한 에셋을 독립 웹서비스에 표시할 수 있는지, 별도 사용 허락·계약이 필요한지 확인 부탁드립니다.
2. 무료 화면과 유료 기능이 함께 있는 서비스, 광고·소개 페이지에서 사용하는 경우 조건이 달라지는지 궁금합니다.
3. 원본 CDN 직접 링크와 자체 서버 저장 중 허용 방식, 리사이즈·WebP 변환·크롭·원형 마스크·색상 변경의 허용 범위를 알려주세요.
4. 게임 UI를 참고하여 SVG로 재작성한 역할/모드 기호에 적용되는 조건도 확인 부탁드립니다.
5. 필요한 저작권·상표 고지, 출처 링크, 비공식 서비스 안내 문구와 표시 위치를 알려주세요.
6. 귀사가 안내할 수 있는 권리 범위와, 별도로 문의해야 하는 원본 권리자·담당 부서가 있다면 알려주세요.

첨부 예정: `game-assets-inventory.csv`, 위 사용 화면 캡처, 서비스 기능·수익 구조 설명. **이 문서는 초안이며 발송하지 않았다.**
