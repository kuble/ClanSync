마지막 갱신: 2026-09-25

**초점:** 클랜 통계 3영역의 1차 구현을 QA에서 확인하고 남은 집계·권한 범위를 완성한다.

## 실행 제약

- **QA 우선, 운영 DB·운영 배포 보류.** 작업 브랜치: `codex/live-session-formation`. 통계 방문·예측 RLS 마이그레이션 2개를 QA에 추가 적용했다. 운영 적용은 보류한다.
- 사용자 QA: `npm run dev:qa`(3011). 열린 명단을 시드로 초기화하지 않는다. 자동 E2E는 `E2E_SKIP_SEED=1`, 쓰기 테스트는 별도 임시 픽스처를 사용한다.
- 변경 위험에 맞는 검증만 실행한다([기준](../.cursor/rules/agent-auto-tasks.mdc) · [실행법](../e2e/README.md)). main 병합·운영 반영 전에는 전체 회귀·빌드가 필요하다.

## 다음 우선순위

1. [클랜 통계](01-plan/pages/10-Clan-Stats.md)의 3영역·관리 방문 화면 1차 구현을 QA에서 검토한다. 잔여 항목은 예측 최소 표본, 개인 비공개 오버라이드, 기간·경기 탐색, 우세 예측·요일/시간대 및 원본 이력이다. 구현·검증 범위는 [Phase 2 현황](TODO_Phase2.md)에 기록한다.
   기존 내전 로비·경기 흐름의 QA 피드백과 [보안·기능 리뷰 후속](03-analysis/review-fixes-2026-09-23.md)도 이어간다.
2. 성능: 로컬 통계·관리의 약 10초 집계를 0.7초·0.5초 수준으로 개선했다([측정·검증](TODO_Phase2.md#2026-09-25-클랜-페이지-응답-최적화)). 배포 직후·간헐적 5~6초 편차는 별도 환경 계측이 남아 있다.
3. M8: 접근성 전수 감사, 모든 권한 조합 점검과 PR 필수 CI.
4. 후속: 실력 기반 팀 균형·OCR·대진 진행·클랜 기본정보/리더 위임, 실제 게임 OAuth·유료 결제·알림 전달 연결.
