# 네임카드 기본 이미지

2026-10-29 이미지 교체 준비로 이전 예시 테마·추가 심벌·초상 아틀라스를 삭제했다.

- 기본 방패 상품과 이미지 원본을 제거했다. 오비트·시프트·노드·비콘·스파크 5종을 무료 기본 제공한다.
- 기본 배경·카드 프레임·초상 장식 없음·칭호 없음은 기존 공통 렌더러를 사용한다.
- 새 [노말 배경 5종](../../namecard-backgrounds/normal-v1/README.md)은 별도 원본·비교표로 제작했다. 상점 등록 전 시안이다.
- 테마 분류는 등록된 상품이 없는 상태로 유지한다. 새 이미지와 상품 구성은 후속 작업이다.
- 구매·장착·공개 범위·개인 상점 기능은 유지하며 테스트 상품은 격리 픽스처에서만 만들고 정리한다.
- [노말 심벌 5종](../../symbols/normal-v1/README.md)은 QA 상점에서 구매 없이 바로 적용한다. 공통 네임카드와 댓글 아바타가 선택을 공유하며 미선택 대체 심벌은 오비트다. 사진 등록자는 프로필 사진을 우선한다. 밝은 테마는 검은 잉크, 어두운 테마는 밝은 잉크로 표시한다.
