## 확인된 기록과 구현 연결

현재 `load-clan-badges.ts`의 정규/깜짝 횟수는 종료된 개설 회차다. 새 요청의 승·무·패 조건과 동일하지 않다. 통계의 `normalize-clan-match-records.ts`는 `team1`/`team2`/`draw`/`void`/`unrecorded`를 구분하며 기록 정정·제거를 반영한다. 유효 결과가 있는 기록을 개설 회차 ID로 묶고 정규/깜짝별 고유 회차를 센다. 회차 종료 여부만으로 달성시키거나 경기 개수를 누적하지 않는다. 원본 경기와 편성 라운드의 같은 경기·같은 회차를 중복 계산하지 않고, 유효 결과가 없는 회차와 회차/종류를 확인할 수 없는 기록은 달성 근거로 사용하지 않는다. 기존 50/100회·깜짝 10회와 겹치는 키/종료 회차 기준의 정리는 선택한 그래픽을 연결할 때 함께 검토한다.

장기 동료는 `clan_members`의 현재 `active`와 `joined_at`을 기준으로 각 멤버의 연속 소속 기간을 확인하는 설계다. 10명이 같은 날 가입할 필요는 없지만 각자 최소 기간을 채워야 한다. 탈퇴 후 재가입은 이전 기간을 이어 붙이지 않는다. 재가입 처리에서 시작일이 실제로 갱신되는지 확인하며 `joined_at = null`을 창단일/계정 생성일로 대체하지 않는다. 현재 활성 장기 멤버가 10명 미만이면 해당 단계 미달이며 남은 최고 단계로 돌아가는 안이다.

코칭의 확정 집계 단위는 `clan_board_posts.kind = feedback`이고 `status = complete`인 클랜 전체의 고유 신청이다. 같은 신청의 댓글/완료 토글/수정은 중복 횟수가 아니다. 담당 선생님 지정·실제 답변을 완료 증빙으로 요구하는 보완안은 적용 시 확정한다. 현재 상태는 신청자·선생님·운영진이 변경할 수 있으므로 빈 신청의 상태 변경만으로 실제 코칭을 증명하는지는 별도 문제다. 최초 완료 날짜를 복원할 수 없는 과거 자료의 날짜를 추정하지 않는다.

게시글의 확정 집계 범위는 `kind = free`인 클랜 전체 자유 게시판의 고유 글이다. 댓글/공감/조회수/편집 횟수와 사진·피드백·채널·공지는 포함하지 않는다. 삭제된 글과 코칭 완료 취소 후 누적 판정은 적용 시 확정한다.

## 표시와 제작

금빛 테두리·같은 계열의 외곽을 유지하고 내부 검/지도/번개/동료의 결속/배움/이야기가 단계적으로 커진다. 문양 요소 수는 성장의 상징이며 실제 횟수/인원과 일대일 대응하지 않는다. 이름·조건·날짜는 케이스 바깥에 둔다.

단계형은 기존 공통 `series` 진열을 사용한다. 최고 달성 한 슬롯을 클릭하면 큰 그림·설명·모든 연관 단계의 케이스를 연다. 첫 정규 내전은 독립 슬롯으로 유지한다. 현재 후보는 비교용 PNG이며 확정 후 개별 투명 배지를 제작한다. 발급 판정/기록·권한·스키마 변경과 해당 QA는 그 적용 단계에서 수행한다.
