# 네임카드 기본 이미지

2026-10-29 이미지 교체 준비로 이전 예시 테마·추가 심벌·초상 아틀라스를 삭제했다.

- 유지: [기본 방패](../../../../public/namecards/v1/shield.webp), 1254×1254px 투명 WebP.
- 기본 배경·카드 프레임·초상 장식 없음·칭호 없음은 기존 공통 렌더러를 사용한다.
- 테마 분류는 등록된 상품이 없는 상태로 유지한다. 새 이미지와 상품 구성은 후속 작업이다.
- 구매·장착·공개 범위·개인 상점 기능은 유지하며 테스트 상품은 격리 픽스처에서만 만들고 정리한다.
