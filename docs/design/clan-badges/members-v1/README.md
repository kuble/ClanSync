# 멤버 인원 달성 배지 디자인 후보

제작일: 2026-10-14 · 상태: **4번 우리의 성채 선택·적용**

클랜 멤버 **10명·20명·50명·100명** 달성 배지를 위한 다섯 가지 스타일이다. 각 PNG는 한 스타일의 4단계를 왼쪽부터 10명 → 20명 → 50명 → 100명 순서로 비교한다.

## 스타일 5종

| 번호 | 최종 비교 시안 | 모티프 |
|---|---|---|
| 1 | [원탁의 동료](01-round-table.png) | 같은 자리에 모이는 동료가 늘어나는 원탁 |
| 2 | [이어진 인연](02-linked-bonds.png) | 서로 맞물리며 단단해지는 연결 고리 |
| 3 | [모여드는 별](03-gathering-stars.png) | 한 사람 한 사람이 모여 완성되는 별자리 |
| 4 | [우리의 성채](04-shared-citadel.png) | 멤버와 함께 커지는 클랜의 보금자리 |
| 5 | [함께 든 깃발](05-united-banners.png) | 같은 별 아래 모여드는 여러 깃발 |

사용자는 4번 **우리의 성채**를 선택했다. 외곽과 금속 색을 유지하고 인원이 늘수록 내부 탑과 성벽이 커지는 방식이다.

## 선택한 개별 배지

| 활성 멤버 | 성장 단계 | 적용 원본 |
|---|---|---|
| 10명 | 첫 탑 1개 | [10명 PNG](../../../../public/clan-badges/members-shared-citadel-10.png) |
| 20명 | 탑 3개·작은 성채 | [20명 PNG](../../../../public/clan-badges/members-shared-citadel-20.png) |
| 50명 | 탑 5개·넓어진 성벽 | [50명 PNG](../../../../public/clan-badges/members-shared-citadel-50.png) |
| 100명 | 탑 7개·완성된 성채 | [100명 PNG](../../../../public/clan-badges/members-shared-citadel-100.png) |

사용자 확정 규칙은 **현재 활성 클랜원 수 기준·미달 시 회수**다. 가입 대기·탈퇴·차단 인원은 제외하며 조건에 미달하면 발급 기록을 회수하고 대표 진열에서도 제외한다. 획득일은 서버에서 처음 조건을 확인한 시각이며 같은 배지를 보유하는 동안 보존한다. 재획득하면 새 확인 시각을 저장한다. 과거 인원 달성 시점을 추정하지 않는다.

`멤버` 컬렉션에서 네 단계와 획득 방식·진척을 표시한다. 미획득 홈은 10명 배지의 아치 실루엣을 공유한다. 기존 발급/대표/확인 테이블을 사용하며 DB 스키마 변경은 없다.

## 공통 디자인 기준

- 기존 첫 깃발·자라는 역사의 입체 금속/에나멜 제작 질감을 참고했다. 모든 단계는 금빛 금속·에메랄드·민트·아이보리 팔레트를 유지한다.
- 인원이 늘수록 좌석·고리·별·탑·깃발이 모이며 문양을 완성한다. 사용자는 같은 성장 방식을 [주년 배지](../anniversary-growth-v2/README.md)에도 적용하도록 선택했다.
- 문양 요소 수는 모임의 성장을 상징하며 실제 인원수와 일대일 대응하지 않는다. 인원 표기는 배지 바깥에 둔다.
- 성채는 1·3·5·7개 탑, 깃발은 2·3·5·7개 깃발로 성장한다. 별자리는 큰 중심별 주위에 작은 별이 2·4·6·8개로 늘어난다.
- 누적 내전 참가자 수와 별개의 현재 활성 클랜 멤버 인원 계열이다.

## 제작·검증 기록

내장 `image_gen.imagegen`을 사용해 기본 비교 시안 5장을 만들고, 별자리의 50명 및 성채/깃발의 100명 단계를 부분 편집한 최종 5장을 저장했다. 전체 최초 요청과 부분 편집 요청은 [prompts.json](prompts.json)에 보관했다.

생성 원본을 이미지 편집 없이 복사하고 파일 해시·크기·다섯 링크를 확인했다. 각 시안의 4개 배지·인원 표기·기본 스타일 일관성·단계별 차이를 육안으로 검토했다. 비교용 배경을 포함한 PNG는 선택 이력으로 보존한다.

선택 이후 각 단계를 내장 `image_gen.imagegen`으로 분리해 1254 × 1254px RGBA 개별 PNG 4종을 제작했다. 전체 요청은 [production-prompts.json](production-prompts.json)에 보관하며 생성 원본을 수정 없이 복사했다. 활성 9→10→9명 판정, 대기 인원 제외, 획득일 보존·대표 지정/회수·모바일 표시는 [격리 E2E](../../../../e2e/clan-badge-growth.spec.ts)로 검증했다.
