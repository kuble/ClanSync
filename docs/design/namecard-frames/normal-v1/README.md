# 노말 네임카드 프레임 · 초상 5종 / 카드 5종

2026-10-29. 기본 제공 무료 디자인이다. 단색 선과 기본 도형만 사용하며 그림·질감·애니메이션은 포함하지 않는다.

- [카탈로그](../../../../src/lib/profile/frames.ts)와 [공통 렌더러](../../../../src/components/profile/namecard-frame-artwork.tsx)를 사용한다. CSS 선·도형으로 그려 비율과 크기에 대응하고 별도 비트맵은 만들지 않는다.
- 초상 프레임은 심벌 주위에만, 카드 프레임은 카드 외곽에만 배치한다. 네임카드 초상 프레임 적용 시 심벌을 줄여 장식과 겹치지 않게 한다. 기본색은 배경 위의 밝은 선/앱 강조색에 자동 대응하며, 그래파이트·블루·그린·퍼플·로즈·앰버 6색도 무료로 선택한다.
- 두 프레임의 `palette_id`를 각각 저장하고, 상점은 미리보기 후 적용·프로필 꾸미기는 색상 선택 즉시 저장한다. 심벌·배경·다른 프레임의 색상은 유지하며 기본색으로 되돌릴 수 있다. 초상 프레임 색상은 댓글 아바타에도 공유한다. 기본 프레임(장식 없음)에는 색상 선택기를 표시하지 않는다.
- 네임카드·상점 샘플·댓글 아바타가 같은 초상 프레임 렌더러를 사용한다. 카드 장식은 포인터를 받지 않으며 닉네임·칭호·조작 영역을 가리지 않는다.
- QA 개인 상점에 각각 5종을 등록하고 기존 기본 프레임도 유지한다. 계정 공통 선택에 저장하며 현재 QA 사용자의 장착·코인·보유 내역은 변경하지 않는다. 운영 DB·배포는 보류다.

검증: DB 11개·관련 화면 4개·ESLint·타입 포함 빌드 통과. 프레임 10종 미리보기/적용, 새로고침, 상대 프로필/댓글 공유와 320px·390px·큰 화면 표시를 확인했다.

색상 확장 검증: DB 12개·색상 집중 화면 2개·ESLint·타입 포함 빌드 통과. 두 프레임의 6색 미리보기·저장·기본색 복원과 상대 프로필/댓글 색상 공유, 기존 심벌·배경 색상 유지를 확인했다.
