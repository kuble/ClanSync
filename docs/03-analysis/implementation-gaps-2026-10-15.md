# ClanSync 미구현 항목과 개선 제안

기준일: 2026년 10월 15일. 현재 작업 브랜치와 QA 구현을 기준으로 정리했다. 이미 구현된 기능을 다시 개발할 목록이 아니라, 기획의 남은 범위와 다음에 개선할 부분을 구분한 점검표다. 운영 DB 적용과 수동 배포는 현재 보류 상태다.

가장 먼저 마무리할 부분은 실제 게임 계정 인증, 클랜 기본정보·리더 위임, 개인정보 공개 범위, 알림의 운영 연결이다. 결제와 대회 진행은 별도 기능 단위로 추진하는 편이 좋다.

## 읽는 기준

- **미구현**: 목표 기능의 실제 사용 경로가 아직 없다.
- **일부 구현**: 화면·기초 데이터는 있지만 목표 흐름의 일부가 남아 있다.
- **결정 필요**: 조건·공개 범위·운영 정책을 먼저 확정해야 한다.
- **운영 연결·검증**: 코드가 있는 기능의 상시 실행·외부 서비스·운영 품질 확인이다. 미구현 기능과 구분한다.
- **추가 제안**: 이번 점검에서 제안하는 개선이다. 확정 기획으로 취급하지 않는다.

우선순위는 P1(핵심 운영·신뢰), P2(주요 기능 완성), P3(확장·편의) 순이다. 개발 순서를 위한 제안이며 기존 플랜·권한 정책을 변경하지 않는다.

## 추가하면 좋은 개선 제안

아래는 확정된 미구현 요구와 별개의 제안이다.

1. **멤버 운영 이력**: 승격·강등·강퇴·리더 위임의 실행자/시각/사유를 한 화면에서 조회한다. 구성원 관리 사고를 추적하기 쉬워진다.
2. **설정 변경 이력과 되돌리기**: 자동 저장은 이미 있다. 알림 채널·내전 규칙·공개 범위의 변경 전후와 복원 가능 범위를 추가하면 실수를 복구하기 쉽다.
3. **통계 정의·집계 시각 안내**: 제목 툴팁에 분모·제외 조건과 마지막 집계 시각을 함께 보여 준다. 수정 직후 수치가 달라지는 이유를 이해하는 데 도움이 된다.
4. **알림 진단 화면**: 실제 발송 테스트, 봇 권한/채널 접근 상태, 최근 성공·실패·재시도 결과를 운영진이 확인하게 한다. 초기 Discord 연결 문제를 줄일 수 있다.
5. **개인 기록과 구성원 목록 왕복 복원**: 이번 개인 기록 링크에 더해, 돌아왔을 때 닉네임 검색·활동 필터·페이지·스크롤까지 복원한다.
6. **신청 처리의 일괄 작업**: 여러 가입 신청을 검토하고 허용된 범위에서 일괄 처리하되, 대상별 실패와 재시도를 구분한다. 개별 처리 흐름을 대체하지 않고 보완한다.
7. **빈 화면에서 다음 행동 연결**: 기록 없는 클랜에서 내전 개설·공지 작성·코칭 선생님 등록처럼 현재 권한으로 가능한 행동을 바로 제시한다. 별도의 큰 안내 카드보다 기존 빈 영역 안에 배치한다.
8. **공통 UI 시각 회귀**: 지금 정리한 탭·팝업·툴팁·자동 저장·표를 320/390/태블릿/데스크톱 기준으로 관리한다. 긴 닉네임·0건·많은 행·오류/갱신 상태도 대표 화면에 포함한다.

## 이미 구현됐으므로 미구현으로 세지 않은 항목

- 통계 4영역, 월/연 필터, 방문 통계와 날짜/월별 방문자 이름 툴팁.
- 투표 상태 분류·예약 시작·단일/다중 선택·도넛 결과·공개 참여자 확인.
- 클랜 게시판의 글/댓글, 코칭 담당 선생님·신청 알림, 방송 링크와 수동 생방송 표시, 추억 사진 목록.
- 배지 계열별 최고 단계 진열·획득/회수·새 배지 확인 상태.
- 프로필의 가입 신청 목록·신청 취소와 네임플레이트/배지 설정.
- 스크림 양측 확정·동시성 보정과 일정 연결, 승부예측의 실제 코인 풀 정산·마감 경합 처리.
- Discord/자동 종료 설정의 자동 저장·오류 재시도. 이번 구성원 목록의 게임 인증 표시·이메일 제외·개인 기록 링크.

일부 PRD·슬라이스·오래된 체크리스트에는 통계 전체가 여전히 ‘구현 대기’로 적혀 있거나 이미 구현한 가입 신청 목록·댓글·양측 확정이 후속으로 남아 있다. 이 표기를 그대로 개발 수량으로 세지 말고 최신 기능 명세·코드·검증 기록과 맞춰 정리해야 한다. 이미 제거한 카카오 알림톡·방송 자동 조회·클랜 외부 경쟁 지표도 자동으로 복원할 개발 항목이 아니다.

## 추천 착수 순서

1. 실제 게임 인증과 클랜 기본정보·리더 위임의 정책/화면을 먼저 확정한다.
2. 개인 공개 범위와 운영 변경 이력을 갖추고, Discord 상시 워커·실발송과 PR 품질 게이트를 마무리한다.
3. 통계 조건 복원·내보내기·소표본 기준을 완성한다.
4. 실력 기반 밸런싱·OCR 또는 대진 진행 중 실제 사용 빈도가 높은 한 기능을 선택해 완성한다.
5. 결제·시즌 성취·다국어·커뮤니티 확장은 운영 수요와 정책 준비에 맞춰 진행한다.
