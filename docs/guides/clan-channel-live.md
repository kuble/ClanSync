# 방송 상태 수동 표시

2026-10-14 사용자 요청으로 외부 API 어댑터·조회 경로·주기적 호출을 제거했다. 이후 요청에 따라 작성자가 직접 생방송 표시를 켜고 끄는 방식으로 제공한다. 외부 API 키는 사용하지 않는다.

방송 이름·시간과 최대 4개 플랫폼 링크를 등록한다. 상세의 `생방송 표시`는 작성자에게만 제공하며 목록에도 같은 상태를 보여준다. 상태는 작성자 설정이고 자동 확인/만료는 없다. 기존 단일 채널과 소개 본문은 보존하며 소개 입력/표시는 제거한다. 현재 동작과 권한은 [게시판 명세](../01-plan/pages/15-Clan-Board.md)를 참조한다.
