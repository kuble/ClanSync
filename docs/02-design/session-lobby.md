# 내전 세션 목록과 방

작성: 2026-09-16

**상태: QA DB·로컬 앱에 구현. 실행 검증 범위는 [Phase 2](../TODO_Phase2.md#2026-09-16-내전-로비·예약)에서 관리한다. 운영 DB 변경과 운영 배포는 보류한다.**

기존 [세션·라운드 용어](../01-plan/glossary.md#내전-운영-용어)와 [방 안의 편성·경기 진행](formation-modes.md)을 따른다. 이 문서는 세션 생성·예약·참여 응답·방 입장·운영 권한만 다룬다.

## 1. 목록에서 방으로

- 첫 화면은 **내전 로비**이며 빈 팀 보드 없이 세션 목록과 추가 버튼을 표시한다. 정규 내전과 깜짝 내전을 구분하고 시작 예정 시각·진행 상태·개설자·참가 현황을 표시한다.
- 정규 내전을 목록 상단에 배치한다. 같은 반복 일정의 진행 세션·다음 예약은 한 줄로 묶고 열린 세션을 대표로 표시한다. 상태는 ‘열림’만 표시하며 다음 예약은 방 정보에서 확인한다.
- 사용자는 세션을 선택해 해당 **방**에 입장한다. 한 클랜에 여러 방이 있어도 현재 선택한 방의 명단·라운드·투표·결과를 유지한다.
- 방마다 고유한 주소와 식별자를 사용한다. 새로고침·재접속·실시간 갱신이 다른 방으로 이동시키지 않는다.
- 로비의 전체 내전 기록은 활동 중인 클랜장·운영진만 조회하며 일반 멤버에게는 아이콘 자체를 숨긴다. 깜짝 내전을 개설한 멤버는 열린 자기 방 안에서 해당 세션 기록만 조회할 수 있다. 서버 액션은 명시한 세션의 개설자·클랜·열림 상태를 확인하며 전체 목록이나 다른 세션 요청은 거절한다.
- 방 안에서는 기존 명단 → 편성 → 필요한 밴픽 → 경기 → 결과 → 다음 라운드 흐름을 이어 쓴다. 목록의 참여 응답과 10명 출전 명단은 별도다.
- 새 방의 첫 라운드는 같은 클랜·게임에서 가장 최근에 열린 **정규 내전**의 편성·표시·맵/영웅 밴 설정을 기본값으로 사용한다. 깜짝 내전에서 바꾼 설정은 이후 방의 기본값에 반영하지 않으며, 주장·명단·투표·진행 상태 같은 세션 전용 값은 복사하지 않는다.

## 2. 종류와 권한

| 구분 | 정규 내전 | 깜짝 내전 |
|---|---|---|
| 개설 | 클랜장·운영진 | 활동 중인 일반 클랜원을 포함한 클랜 구성원. 게스트 제외 |
| 운영 | 클랜장·운영진 | 개설자가 본인 방 운영. 기존 클랜 운영진의 관리 범위는 서버 권한 기준 적용 |
| 일정 | 즉시 시작·예약·매주 반복 일정 | 즉시 시작 또는 N일 뒤 개최 예약 |
| 참가 | 해당 클랜원이 방에 입장 | 예약된 방에 참여 응답·방 입장 |

- 일반 클랜원이 깜짝 방을 만들었다고 다른 방이나 클랜 관리 권한을 얻지는 않는다. 다른 방에서는 참가·투표 등 본인에게 허용된 조작만 한다.
- **임시 진행자 지정:** 클랜장만 정규 내전 방의 진행자를 현재 활동 중인 운영진 중에서 지정·해제한다. 개별 방에만 적용하고 클랜 전체 역할은 바꾸지 않는다. 방이 종료되면 지정도 해제한다. 다른 운영진의 기본 방 운영 권한은 유지한다.
- 화면 표시와 서버의 쓰기 권한을 같은 기준으로 판단한다. 방 식별자만 바꾼 요청으로 다른 방을 조작할 수 없어야 한다.

## 3. 예약·반복·참여 응답

- 정규 내전은 시작 시각을 예약하고 요일·시각을 정해 매주 반복할 수 있다. 반복 규칙과 각 개최분의 방·참여 응답·진행 기록을 구분한다.
- 예약 날짜·시·분·초는 드로워 안의 휠에서 드래그·스크롤·방향키로 선택한다. 별도 캘린더 팝업은 사용하지 않는다. 정규 내전 생성 시 ‘매주 같은 요일·시각’을 켜면 날짜 대신 요일을 선택하고, 가장 가까운 미래의 해당 요일·시각으로 첫 예약을 계산한다. 반복 예약 수정 화면도 요일·시각을 표시하며 저장 시 현재 예약과 이후 반복 기준을 함께 변경한다. 반복 없는 예약은 날짜·시각만 변경한다.
- 깜짝 내전은 목록의 ‘참여’ 버튼으로 신청하고 ‘참여 취소’로 되돌린다. 예약 보기와 미정·불참 선택 UI는 제거한다. 관리 권한이 있는 사용자의 방 정보 메뉴는 유지한다. 새 예약의 응답 받기는 기본 켜짐이며 시작 3일 전부터 신청할 수 있다. N은 기존처럼 1~30일로 설정하거나 끌 수 있고, 기간 밖에서는 참여 불가 사유를 표시한다. 예약 시각 또는 방을 일찍 연 시점부터 신청은 마감된다. 취소는 기존 응답 저장소의 `no`로 저장하며 DB 스키마는 변경하지 않는다.
- 참여 응답은 세션에 대한 참석 의사다. 응답 변경만으로 라운드 명단, 역할 선호, 팀 편성, 경기 결과를 자동 변경하지 않는다.
- 깜짝 내전은 진행 중 동기화·재접속을 위한 임시 데이터만 저장한다. 종료 확인 후 세션·방·모든 라운드·점수·역할 선호·맵/영웅 투표·참여/예측 응답을 같은 DB 트랜잭션에서 연쇄 삭제한다. 정규 기록은 보존한다. 깜짝 결과는 영구 통계·명예의 전당과 코인 보상에서 제외한다. 변경 전 이미 종료된 기록의 일괄 삭제는 이번 마이그레이션에 포함하지 않는다.
- 참여 응답하지 않은 사람의 사이트 입장·관전 가능 여부와 기능별 참여 자격은 기존 클랜 접근·투표·승부예측 규칙을 따른다. 응답 자체로 운영 권한을 얻거나 출전이 확정되지 않는다.
- 예약 시각, 실제 세션 개설 시각, 라운드 시작 시각을 구별한다. 내전 날짜는 기존 세션 기준을 유지하며 예약 생성일로 덮어쓰지 않는다.
- QA DB의 예약 작업은 매분 실행한다. 예약 시각이 지난 방을 열고 다음 반복 예약을 한 건 생성한다. 지연된 회차를 몰아서 생성하지 않는다. 반복을 끄면 현재 예약은 남고 이후 회차 생성만 멈춘다.
- 반복 예약의 이름·요일·시각 변경은 현재 예약과 이후 반복 일정에 함께 적용한다. 개설자가 탈퇴하거나 정규 내전 개설 권한을 잃으면 예약은 취소하고 반복을 중지한다.

### 세션 자동 종료

- 새 클랜은 자동 종료를 사용하며 기본값은 마지막 입력 후 3시간이다. 클랜장·운영진은 `클랜 관리 > 내전 관리 설정`에서 기능을 끄거나 1~168시간으로 바꿀 수 있다.
- 라운드 편집, 이번 라운드 역할 선호, 맵·영웅 투표, 승부예측을 세션 입력으로 본다. 예약 참여 응답은 아직 열리지 않은 방의 의사 표시이므로 진행 중 세션 활동에는 포함하지 않는다.
- QA DB 작업은 1분마다 만료 세션을 확인한다. 진행 중인 결과 미정 라운드는 `무효`로 닫고 방도 종료한다. 정규 기록은 남으며 깜짝 내전은 기존 종료 트리거에 따라 휘발성 데이터를 삭제한다. 기능 도입 전에 열려 있던 세션은 배포 시각이 아니라 확인 가능한 마지막 라운드·예측·역할 선호 시각부터 계산한다.

## 4. 조회·동기화 기준

- 승부예측 제출·수정은 정규 내전만 허용한다. 서버 액션과 DB 제한 정책이 방 종류를 검사하며 기존 Premium·관전자·예측 마감 조건도 함께 적용한다. 깜짝 내전에서는 직접 요청으로도 참여할 수 없다.
- 깜짝 개설자는 즉시/예약 및 신청 기간 여부와 관계없이 자동 참여한다. 참여는 출전 슬롯 배정과 별개이며 기존 활성 방에는 누락된 응답만 보완하고 명시적 취소는 유지한다. 로비의 입장/참여와 더보기 영역은 고정 열로 정렬해 버튼 유무에 따른 위치 변화를 없앤다.
- 목록은 클랜의 여러 방을 조회한다. 방 화면은 선택한 방 → 연결된 세션 → 해당 세션의 현재 라운드 순으로 좁혀 조회한다.
- ‘클랜 전체의 닫히지 않은 라운드 한 개’ 또는 ‘가장 최근 세션 한 개’를 현재 방으로 간주하지 않는다. 같은 방 안에서는 현재 라운드를 하나로 유지한다.
- 명단 저장·역할 선호·설정·밴픽·베팅·다음 라운드·종료 요청은 대상 방/세션/라운드의 관계와 호출자 권한을 검증한다.
- 다른 방의 변경 때문에 현재 방의 선택이나 미저장 입력이 바뀌지 않아야 한다. 방 종료·다음 라운드·예약 상태 변경은 해당 목록과 방에 반영한다.
- 통계·내전 기록은 기존 세션 및 라운드 식별자로 묶는다. 같은 날짜의 여러 방을 하나의 세션으로 합치지 않는다.

## 5. 집중 검증 기준

DB·브라우저의 검증 범위를 구분하며 실행 결과는 Phase 2에 기록한다.

- [x] 같은 클랜의 정규·깜짝 방 생성·명단 격리를 브라우저에서, 방별 라운드·설정·종료 권한을 DB에서 확인했다. 기존 밴픽 시나리오도 방 입장 후 통과했다.
- [x] 일반 클랜원은 깜짝 내전을 개설하고 본인 방을 운영할 수 있으며 정규 내전 개설·타인 방 운영은 거절된다. 서버는 active member/officer/leader만 개설을 허용한다.
- [x] 클랜장의 정규 방 진행자 지정·해제와 방 종료 시 해제가 해당 방에만 적용된다.
- [x] 예약·매주 반복의 다음 개최분을 중복 생성하지 않고 각 개최분의 응답과 기록을 구분한다. 반복 중지·취소·동시 자동 개장·권한 상실은 DB에서 확인했다.
- [x] 참여 응답 변경·새로고침 후 보존과 출전 명단 불변을 확인한다. 사전·마감 후 응답과 타인 응답 쓰기는 DB에서 거절된다.
- [x] 두 브라우저의 서로 다른 방 진입·저장·재접속 후 명단과 URL 유지를 확인했다. 동시 다음 라운드 생성은 DB에서 검증했다.
- [x] 기존 편성·밴픽·기록 흐름이 새 목록/방 진입 후에도 유지된다. 기존 세션은 마이그레이션에서 방과 연결해 보존한다.

쓰기 검증에는 별도 임시 클랜·사용자를 사용한다. 사용자 테스트 중인 QA 방·명단은 시드나 검증으로 초기화하지 않는다.
