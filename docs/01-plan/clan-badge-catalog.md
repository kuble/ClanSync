# 클랜 배지 확장 후보

2026-10-14 사용자 요청에 따른 브레인스토밍이다. 주년 계열은 후속 사용자 선택으로 1·3·5·10주년의 [자라는 역사](../design/clan-badges/anniversary-v1/README.md)를 확정·적용했다. 아래 나머지 후보의 이름·수치·발급 정책·구현 범위는 미확정이다. 단계형 계열은 여러 핀으로 확장할 수 있다.

클랜 배지는 클랜 공동의 기록과 이야기를 수집한다. 개인의 승률·실력 등급·MVP는 개인 배지와 구분한다.

- A: 기존 서비스 기록을 바탕으로 조건을 설계할 수 있는 후보. 현재 자동 발급된다는 뜻은 아니다.
- B: 기존 기록에 추가 집계 규칙·기간/대상 정의가 필요한 후보.
- C: 새로운 기록·행사 태그·상호 확인 또는 증빙이 필요한 후보.

현재 구현은 창단, 정규 1/10/50/100/500회, 깜짝 1/10회, 1/3/5/10주년의 12종이다. 현재 정규 100/500회 표시 이름의 종류 구분은 확장 때 함께 검토한다.

## 발급·수집 규칙 후보

1. 숫자 계열은 동일 문양에 에나멜 색·테두리·작은 각인을 달리한다. 이름과 조건을 읽지 않아도 계열이 보이게 한다.
2. 기본 수집은 소규모 클랜도 빠르게 첫 성취를 얻고, 큰 클랜용/장기 계열은 별도 구획으로 둔다.
3. 새 누적 배지는 실제 진행된 기록·고유 참여자·서로 다른 날짜를 함께 검토한다. 예약 개수·취소·중복·임시 테스트 기록만으로 발급하지 않는다.
4. 게시물/댓글/사진 계열은 고유 참여자를 우선하고 동일 작성자의 하루 반복 기여를 제한하는 안을 검토한다. 수량만 보상하는 후보의 우선순위는 낮춘다.
5. 배지는 장식/기념이다. 팀 편성 점수·운영 권한·게임상 우위를 보상으로 붙이지 않는 안을 권한다.
6. 수정/삭제/탈퇴/기록 정정이 획득에 미치는 영향을 종류별로 정한다. 현재 12종의 정정 시 판정 정책을 이 초안으로 변경하지 않는다.
7. 행사 배지는 클랜 운영진 임의 발급, 복수 확인, 서비스 확인 중 발급 권한을 결정해야 한다. 인증된 대외 우승처럼 보이는 자기 선언을 피한다.
8. 기본 진행도와 한정/히든을 분리하고, 미획득 모든 핀을 처음부터 한 화면에 펼치지 않는다. 다음 성취 2~3개와 컬렉션별 케이스를 검토한다.
