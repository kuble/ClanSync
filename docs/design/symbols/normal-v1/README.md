## 제작 규격

- 색상: 기본 흑백과 공통 6색을 상점/프로필에서 선택하고 `emblem` 선택의 `palette_id`로 저장한다. 컬러 심벌은 원본의 투명 영역을 CSS 마스크로 재사용한다. 네임카드와 게시글·댓글 아바타가 같은 렌더러를 사용하며, 기본색은 밝은/어두운 테마에 맞춰 흑백으로 표시한다. 프레임·배경·칭호 선택은 유지한다.

- 투명 배경, 128×128 viewBox, 단일 잉크 `#E8EFEC`. 광택·그라데이션·질감·입체·애니메이션 없이 실루엣으로 구분한다.
- [SVG 원본](../../../../public/symbols/normal-v1)은 확대하거나 CSS 알파 마스크로 사용한다. 색 변경은 단색 전체에 적용한다. 밝은 배경에서는 어두운 잉크를 사용한다.
- 같은 위치의 WebP는 투명 512×512 무손실 출력이다. 색상별 원본을 복제하지 않는다.
- [비교표](contact-sheet.png)는 큰 형태, 24/32/48px, 밝고 어두운 배경, 32px 네임카드 적용 예를 포함한다.
- QA 개인 상점의 심벌 분류에 5종 모두 노말·기본 제공(0코인)으로 등록했다. 구매 없이 즉시 적용하고 네임카드·댓글 아바타에서 공유한다. 기본 방패 상품은 비활성화하고 원본 파일은 삭제했다. 미선택/이전 코드의 대체 심벌은 오비트다.
- QA 허용 명단 14계정에 기본 심벌·초상 프레임·배경·카드 프레임·칭호를 무작위 적용했다(70개 선택). 코인과 보유 내역 보존을 확인했다. `node scripts/qa-default-namecards.mjs --apply`로 재적용한다. 운영 DB·배포는 보류다.
