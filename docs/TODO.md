# 현재 작업

**현재 초점: 기획·디자인 고도화안을 주제별로 구체화한다.**

마지막 갱신: 2026-09-16 — [고도화 논의 문서](01-plan/product-design-evolution.md)의 `D-UX-01` 구체화 중. **범례 제거·선택자 숨김안·위 명단 직접 드래그 이동/교환을 반영.** 고정 역할·순서 자동 입력·우클릭 삭제는 유지한다. Ctrl+Z·검색 초점 단축키와 추가 편의성 후보를 정리했다. 대기방 연결 적용 방향은 확정, 게임사 문의는 후속이다. 숨김안·모바일·저장·OCR·밴픽은 OPEN이며 실제 앱 구현 완료와 구분한다.

목업 기준 개편과 로그인·페이지 이동 성능 개선은 운영 반영 완료. Phase 2 전체 종료 감사(M8)는 별도다.

기존 구현 검증(2026-09-15): 브라우저/로직 회귀 43건·빌드·타입·src 린트 확인. 페이지 서버 서울 배치 후 운영 3회 중앙값: 로그인 8.2→1.9초, 관리 10.6→1.4초. Vercel production READY. DB는 기존 마이그레이션 50개·테스트 24개 검증 상태를 유지한다.

## 구현 재개 시 남은 우선순위

1. 성능: 배포 직후·간헐적 5~6초 응답 편차 추가 계측. 원인은 아직 확정하지 않았다.
2. M8: 접근성 전수 감사, 모든 권한 조합 점검과 PR 필수 CI.
3. 목업에만 있는 기능: 자동 팀 편성·대진 진행·클랜 기본정보 편집/리더 위임 등 범위 확정 및 구현.
4. 실제 게임 OAuth·유료 결제·알림 전달 서비스 연결.
