# 자라는 역사 — 주년 성장형 V2

제작일: 2026-10-14 · 상태: **1·3·5·10주년 선택·적용**

사용자는 멤버 배지의 [우리의 성채](../members-v1/README.md)처럼 내부 그림이 고도화되는 방식을 주년 배지에도 적용하도록 요청했다. 기존 자라는 역사의 방패·아이보리 바탕·에메랄드/민트 에나멜·금빛 줄기와 별을 유지하고, 잎과 줄기·뿌리의 성장으로 연차를 구분한다.

모든 주년의 테두리는 첫 깃발·우리의 성채와 같은 **금빛 금속**으로 통일한다. 사용자의 후속 요청에 따라 검은 테두리를 금빛으로 교체하고 내부 나무의 성장은 유지한다. 같은 외곽 안에서 나무가 자라므로 케이스 홈도 1주년 실루엣을 공유한다.

| 주년 | 성장 단계 | 적용 원본 |
|---|---|---|
| 1주년 | 잎 3개·가는 줄기·작은 뿌리의 묘목 | [1주년 PNG](../../../../public/clan-badges/anniversary-growing-history-1y-gold-v2.png) |
| 3주년 | 잎 5개·가지가 뻗는 어린 나무 | [3주년 PNG](../../../../public/clan-badges/anniversary-growing-history-3y-gold-v2.png) |
| 5주년 | 잎 7개·굵어진 줄기와 넓어진 뿌리 | [5주년 PNG](../../../../public/clan-badges/anniversary-growing-history-5y-gold-v2.png) |
| 10주년 | 잎 9개·풍성한 수관과 깊은 뿌리의 큰 나무 | [10주년 PNG](../../../../public/clan-badges/anniversary-growing-history-10y-gold-v2.png) |

잎의 수는 성장 단계를 표현하며 실제 연차와 일대일 대응하지 않는다. 이름·획득 방식·획득일은 케이스 바깥에서 읽는다. 기존 배지 키와 창단 시각에 해당 UTC 연도를 더한 획득일, 발급/대표/확인 기록과 권한은 유지한다.

## 제작·검증 기록

내장 `image_gen.imagegen`으로 기존 자라는 역사 배지를 참조해 개별 성장 PNG 4종을 생성한 뒤, 성채의 금빛 마감을 참고해 바깥 테두리만 편집했다. 1254 × 1254px RGBA 원본을 수정 없이 복사하고 해시·크기·투명 모서리를 확인했다. [나무 제작 요청](prompts.json)과 [금빛 마감 요청](finishing-prompts.json)을 보관한다. 각 단계의 잎·줄기·뿌리 차이와 같은 제작 질감을 육안으로 검토했다.

전체 케이스와 대표 진열은 공통 이미지 경로를 사용한다. 격리 [성장 배지 E2E](../../../../e2e/clan-badge-growth.spec.ts)에서 네 주년의 획득과 이미지 로딩을 확인했다. 이전 [금속 등급 V1](../anniversary-v1/README.md)과 마감 후보는 디자인 이력으로 보존한다. 이번 변경에 DB 스키마·운영 적용은 없다.
