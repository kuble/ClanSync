# 미가입 참가자와 계정 연결

2026-10-15 확정 요구: 가입 없이 반복 출전·기록 누적, 동명이인 별칭, 가입 후 운영진 승인 연결, 잘못된 연결 취소.

## 구현 경로

- 클랜 관리 → 구성원 → **내전 참가자 명부**. 운영진이 회원의 별칭을 수정하거나 미가입 참가자를 추가한다. 내전의 참가자 목록에서도 추가할 수 있다.
- 미가입 참가자의 **연결 링크**를 발급하여 당사자에게 전달한다. 로그인/가입 후 해당 링크에서 본인 계정의 연결 요청을 보낸다. 신청 화면과 운영진의 이력에는 동일한 계정 구분 코드가 표시된다.
- 운영진은 **계정 연결 요청·이력**에서 본인을 확인하고 사유와 함께 승인/거절한다. 승인된 요청은 취소 사유를 남겨 되돌릴 수 있다. 링크 재발급은 이전 링크를 만료시키며 승인 시 링크를 폐기한다.

## 기록과 권한

- 참가자 ID는 변하지 않는다. 기존 회원의 참가자 ID는 기존 user ID를 유지하여 원본 명단을 이관하지 않는다. 미가입 참가자에는 별도 UUID를 발급한다. 닉네임·별칭·프로필 이미지는 식별 키가 아니다.
- 원본 라운드/경기·평가 점수는 참가자 ID로 남기고 조회 모델에서 승인된 계정으로 연결한다. 승인/취소는 조회 모델을 같은 트랜잭션에서 다시 만든다. 코인·승부예측·클랜 가입/역할은 변경하지 않는다.
- 신규 편성은 활동 회원 또는 명부의 미가입 참가자를 선택한다. 연결된 참가자가 활동 회원이면 다음 내전부터 회원 항목을 사용한다. 연결 당시 진행 중인 내전에 참가했다면 종료 후 승인/취소한다.
- 같은 경기에서 이미 두 참가자로 출전한 기록이 있으면 연결을 거부한다. 자동으로 두 출전을 합치지 않는다. 운영진이 경기 기록을 정정한 뒤 다시 신청/승인한다.
- 미가입 참가자는 별칭을 필수 입력하고 클랜 내 별칭은 대소문자를 무시해 중복을 막는다. 기존 회원도 운영진이 별칭을 지정할 수 있다. 별칭 없는 기존 동명이인은 짧은 참가자 ID를 붙여 구분한다.
- 운영진이 발급한 30일 연결 링크로 로그인한 본인이 신청한다. 클랜 가입은 신청 조건이 아니며 링크는 기록 조회 권한을 주지 않는다. 운영진이 확인한 요청만 승인한다. 승인한 요청의 취소 사유·처리자·시간을 남기고 원본 기록은 보존한다.
- OCR, 닉네임만으로 자동 연결, 임의 계정 생성, 자동 소유권 인정은 이번 범위에 포함하지 않는다.
