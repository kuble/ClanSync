# 네임카드 배경 · 노말 5종

2026-10-29 제작. 레일·웨이브·폴드·스텝·타일의 정적 패턴이다. [제작 목록](manifest.json) · [비교표](contact-sheet.png).

| 이름 | 색 계열 | 도형 |
| --- | --- | --- |
| 레일 | 슬레이트 | 짧은 가로선과 작은 사각형 |
| 웨이브 | 네이비 | 가장자리에서 퍼지는 원호 |
| 폴드 | 포레스트 | 겹치지 않는 사선 띠 |
| 스텝 | 앰버 | 높이가 줄어드는 세로 막대 |
| 타일 | 플럼 | 어긋나게 반복되는 사각형 |

- SVG 원본은 960×240(4:1), WebP는 1280×320 무손실이다. [원본 폴더](../../../../public/namecard-backgrounds/normal-v1).
- 한 가지 바탕색과 한 가지 패턴색만 사용한다. 그라데이션·광택·질감·테마 일러스트·애니메이션은 넣지 않는다.
- 닉네임이 놓이는 왼쪽/중앙은 비우고 가장자리에 패턴을 둔다. 심벌은 배경에 구워 넣지 않는다.
- 실제 적용 시 주 글자 `#F1F5F3`, 보조 글자 `#C3D0CA`를 사용한다. 밝은/어두운 앱 테마 모두 배경 위의 글자는 이 밝은 전경색을 유지해야 한다.
- 4:1 원본과 6:1/3:1 중앙 크롭에서 글자 대비 4.5:1 이상을 검사한다. 비교표에는 별도 레이어의 기본 심벌과 닉네임을 합성한 320×80·240×80·264×44 예를 넣었다.
- QA 개인 상점에 5종 모두 노말·무료 기본 제공으로 등록했다. 기존 기본 배경도 유지하며 구매 없이 적용하고 계정 공통 네임카드에 저장한다. 밝고 어두운 테마 모두 배경 위 심벌·닉네임·칭호의 밝은 전경색을 유지한다.
- QA 14계정에는 배경만 새 5종 중 무작위 적용했다. `node scripts/qa-default-namecards.mjs --backgrounds-only --apply`로 재적용하며 기존 심벌·칭호·다른 장착·코인·보유 내역 보존을 검증한다. 운영 DB·배포는 보류다.

재생성·검증: `node scripts/build-normal-namecard-backgrounds.mjs`

## 색상 바리에이션

- 5개 패턴에 그래파이트·블루·그린·퍼플·로즈·앰버 6색을 공통 제공한다. 별도 상품·추가 비용 없이 상점 카드/미리보기에서 비교한 뒤 적용하며, 프로필 꾸미기에서는 현재 배경의 색상을 바로 저장한다.
- 공통 `CosmeticColorPicker`와 팔레트를 재사용한다. 패턴은 `masks/*.svg` 한 장씩 유지하고 CSS 마스크로 칠한다. 패턴색 불투명도 40%로 모든 색상의 주/보조 글자 대비 4.5:1 이상을 검사한다.
- 계정 선택의 `palette_id`에 색상을 저장하며, 미선택은 패턴별 기본색으로 표시한다. 본인·클랜원 조회 모두 같은 값을 사용한다. 미리보기만 변경하거나 닫으면 저장하지 않는다. QA 스키마만 적용하며 기존 선택·잔액·보유 내역은 바꾸지 않는다.
- 검증: DB 10개·관련 브라우저 2개·5패턴×6색 전경 대비·ESLint·타입 포함 빌드 통과. [색상 선택 상점](palette-store-desktop.png) · [밝은 테마 모바일](palette-preview-mobile-light.png).

QA 등록 검증: DB 9개·관련 브라우저 3개·ESLint·타입 포함 빌드 통과. [상점 화면](store-desktop.png) · [밝은 테마 모바일 적용](preview-mobile-light.png).
