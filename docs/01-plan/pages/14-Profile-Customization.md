# 14 Profile Customization · 프로필 / 꾸미기

기준일: 2026-10-27. QA 현재 동작을 기준으로 한다. 운영 DB·배포는 별도 승인 전까지 보류한다.

## 화면과 경로

| 경로 | 용도 | 권한 |
| --- | --- | --- |
| `/profile` | 플레이어 소개 / 계정 정보 두 탭 | 본인 |
| `/profile/{userId}` | 기존 링크 호환: 공통 클랜 개인 기록으로 이동 | 로그인 사용자 |
| `/games/{gameSlug}/clan/{clanId}/stats?player={userId}` | 플레이어 소개·개인 기록 통합 | 클랜 구성원; 통계는 기존 열람 권한 적용 |
| `/profile/{userId}/emblems` | 개인 엠블럼 케이스 | 로그인 방문자; 대표 저장은 본인만 |
| `/profile/emblems` | 본인의 현재·탈퇴 클랜 획득 기록 통합 | 본인 |
| `/store` | 네임카드 디자인 비교·구매·공통 적용 | 본인 |

프로필의 진열장·굿즈 보관함·진열장 관리·전용 상점은 제거했다. 해당 기획과 시안은 Git 이력에서 확인한다. [DB 정리 대상과 결과](../../03-analysis/retired-db-storage-2026-10-26.md).

계정 헤더의 게임 선택은 호버·클릭·키보드·터치로 여는 팝업이다. 처음 열 때 실제 등록 게임을 조회하고 준비 중인 게임은 선택을 막는다. 선택은 기존 게임별 클랜 진입 경로로 연결해 인증/소속에 따른 이동을 유지하며, 전체 게임 보기·조회 실패 재시도를 제공한다. 프로필 본문에서는 중복 프로필 링크를 생략하고 프로필/엠블럼/개인 상점의 로고는 `/games`로 연결한다.

## 플레이어 소개

- 본인 화면은 게임 프로필에 공통 네임카드를 통합하고 그 아래에 성별·출생 연도·가입일을 세 열로 묶는다. 넓은 화면에서는 왼쪽 게임/기본 정보와 오른쪽 한 줄 소개/대표 엠블럼을 두 열로 표시하며, 1000px 이하에서는 같은 순서의 한 열로 전환한다. 소개 카드는 탭 본문 폭을 채운다.
- 네임카드에는 선택한 게임의 인증된 배틀태그/라이엇 ID를 표시하고 미연동·미인증·등록된 게임이 없으면 `Player`를 표시한다. 내부 제공자 ID는 표시하지 않는다. 클랜이 없는 연동 게임도 게임 프로필에서 선택할 수 있다.
- 게임 프로필은 클랜·역할·인증된 전체 배틀태그/라이엇 ID를 사용하며 계정 공통 닉네임·아바타는 표시하지 않는다. 상대 플레이어의 소개는 개인 기록 상단에 같은 소개 구성과 계정 공통 칭호·프레임으로 표시한다. 클랜 없는 연동 게임도 선택하며 미인증·미연동은 `Player`다. 본인 전용 기본 정보·네임카드 편집은 방문자에게 제공하지 않는다.
- 여러 클랜이면 게임 아이콘/이름 버튼과 한 장씩 넘기는 캐러셀을 사용한다. 터치 스와이프·방향키/Home/End와 현재 순번 안내를 제공한다. 숨겨진 카드의 링크는 키보드·스크린리더 탐색에서 제외한다. 한 클랜이면 전환 버튼을 생략한다.
- 한 줄 소개는 최대 120자다. 본인만 편집·저장할 수 있으며 취소 시 기존 값을 유지한다. 저장은 계정의 다른 메타데이터를 덮어쓰지 않는다.
- 소개 본문은 테두리와 배경이 있는 영역으로 표시하고 비어 있어도 별도의 `한 줄 소개 편집` 아이콘 버튼을 제공한다. 넓은 화면에서 우측 소개/대표 엠블럼 열은 좌측 게임/기본 정보 열의 높이에 맞추며 세 제목은 15px로 통일한다. 모바일에서는 순서대로 쌓는다.
- 게임 ID 바로 아래에 해당 게임의 부계정 이름을 표시한다. 본인은 등록한 이름을 보고, 개인 기록 방문자는 현재 클랜의 `view_alt_accounts` 설정과 기존 RLS가 모두 허용한 이름만 본다. 부계정 메모·다른 게임 이름은 방문 응답에서 제외한다. 미수신·공개된 항목 없음·여러 이름 모두 동일한 52px 영역을 사용하고 긴 목록은 내부에서 스크롤한다. 본인의 인증된 게임에는 편집 아이콘을 두어 소개/본인 개인 기록에서 추가·닉네임/메모 수정·삭제를 제공하고 저장 후 같은 화면을 갱신한다. 현재 세션의 본인 목록/공개 안내만 편집 창에서 조회하고, 수정 요청은 소유자·기존 행의 게임·현재 인증·공개 동의를 서버에서 재검증한다. 중복/실패는 입력을 유지한다. 계정 정보 탭의 중복 배틀태그·부계정 블록은 제거하고 소개 영역에서 관리한다.
- 개인 기록의 소개 배너는 추가 조회 중에도 완성된 게임 프로필·기본 정보·소개·엠블럼 배치를 유지한다. 알고 있는 카드와 기본 정보·케이스를 먼저 표시하고, 미수신 소개만 자리 표시자로 채운다. 소개는 두 줄 높이를 예약하고 긴 내용은 해당 영역 안에서 스크롤한다. 오류·재시도도 같은 위치에서 처리하며 케이스와 카드를 다시 마운트하지 않는다.
- 본인 소개의 대표 엠블럼은 캐러셀 바깥에 한 번 표시하며 케이스 전체를 하나의 링크로 사용한다. 별도 하단 링크와 상태 행을 제거하고 남은 높이는 소개 영역이 채운다. 로딩/빈 상태는 케이스 크기를 유지하고 보조 안내는 스크린리더에 제공하며, 실패 시 케이스 안에서 재시도할 수 있다. 클랜 프로필 변경과 독립적이다.
- 계정 정보 탭으로 전환해도 소개 상태를 유지한다. 모바일에서는 카드·네임카드가 화면 밖으로 넘치지 않는다.

## 계정 정보와 공통 네임카드

- 공통 네임카드는 각 게임 프로필 안에서 해당 게임 ID와 함께 표시한다. 꾸미기·개인 상점 버튼은 현재 선택한 카드의 클랜 이름·역할 행 오른쪽에 한 번만 제공하고 편집 창을 공유한다. 게임별 선택 대신 계정의 한 구성을 모든 게임·클랜에서 공유하며 게임을 바꾸어도 같은 칭호·프레임을 적용한다. 편집 창 미리보기에도 현재 게임 ID 또는 `Player`를 표시한다.
- 네임카드의 프리셋 엠블럼·이름표·칭호·프레임은 `nameplate_options` 카탈로그, `user_nameplate_inventory` 보유, `user_namecard_selections` 선택을 사용한다. 개인 엠블럼 획득 케이스와는 별도 기능이다.
- 장착은 본인·카테고리·활성 상품·기본/보유 조건을 서버에서 검증한다. 칭호 구매는 개인 코인에서 가격을 확인해 원장·보유 정보를 원자적으로 기록하고 중복 요청은 재차 차감하지 않는다.
- 네임카드의 상점/편집 아이콘은 접근성 이름·초점/hover 도움말과 44px 터치 영역을 제공한다. 선택은 저장 후 공유 네임카드에 반영하며 실패 시 재시도한다.
- 꾸미기 편집은 테마·심벌·초상 프레임·배경·카드 프레임·칭호 분류와 보유 디자인의 네임카드 미리보기 목록을 사용한다. 현재 게임 ID와 나머지 장착 외형을 유지한 후보를 비교하며, 적용 중인 디자인은 체크와 테두리로 표시한다. 상단 현재 적용 모습은 목록 스크롤 중에도 유지하고, 클릭 저장이 성공한 뒤에만 적용 상태를 바꾼다. 새 디자인은 개인 상점으로 연결한다.
- 그림 테마는 심야 아케이드·전술 기록·성운 항해 3종이다. 각 테마의 배경·카드 외곽 프레임·초상 프레임을 무료로 제공하고 세트 적용은 이 세 항목만 한 번에 저장한다. 현재 심벌과 칭호는 유지한다. 심벌과 초상 프레임(`portrait`)은 독립 조합하며, 아케이드/전술은 사각형·성운은 원형이다. 장식 없음으로 초상 프레임만 해제할 수 있다. [제작 에셋·프롬프트](../../design/namecards/v1/README.md).
- 기본 심벌은 시안의 은빛 나침반 방패 이미지다. 초상 장식의 투명 여백은 렌더링에서 보정하며 심벌 중심과 이름 시작점은 테마마다 같다. 카드 외곽 곡률은 일반 12px·소형 7px, 테두리는 2px로 통일한다. 초상 프레임의 원형/사각형 모양과는 독립이다.
- 왕관·불꽃·번개·별·게임패드도 방패와 어울리는 금속·에나멜 질감의 투명 이미지로 표시한다. 기존 심벌 코드와 선택·보유 조건을 유지하고 미리보기/프로필/개인 기록/소형 내전 카드에서 같은 이미지를 사용한다.
- 하단 안내와 상점 이동은 44px 아이콘으로 제공하고 도움말은 hover·초점·터치로 확인한다. 심벌은 기본 방패 외에 왕관·불꽃·번개·별·게임패드 5종을 무료 기본 카탈로그로 제공한다. 게임별 같은 기본 항목만 이름으로 중복 제거하며 서로 다른 무료 심벌은 모두 표시한다. 선택한 심벌의 모양·색을 미리보기·프로필·개인 기록·내전 네임카드에 공통 적용한다.
- 무료 기본 프레임 6종(실버 라인·챔피언 골드·아이스 블루·로즈 쿼츠·듀얼 라인·스티치), 이름표 배경 6종(미드나잇·포레스트·선셋·오로라·체커보드·블루프린트), 칭호 8종을 추가 제공한다. 프레임·배경·심벌·칭호는 독립적으로 조합한다. 칭호 숨김은 `*-sub-default`인 명시적 해제 항목에만 적용하며 무료 칭호도 본인·공개 소개·클랜 공유 카드에 문구를 표시한다. 기존 유료 상품의 보유 조건과 코인 잔액은 유지한다.
- 기존 Premium 프레임은 기존 보유·구매 조건을 유지한다. 구매 취소/환급으로 보유를 회수하면 계정 공통 장착에서도 해제한다.
- 편성자에게만 편성 중 장식을 숨긴다. 다른 참여자와 이후 단계에는 표시한다.
- 운영 조작이 없는 내전 출전 슬롯은 네임카드가 너비·높이를 채우고 12px 곡률을 사용한다. 팀 슬롯의 중첩 테두리·안쪽 패딩을 제거하며 성적/점수 표시는 카드 안에 배치한다. 운영진의 직접 점수 입력은 기존 조작 영역을 유지해 팀 선택·편집 동작과 겹치지 않게 한다.

## 게임별 관리·가입 신청

- 게임별 관리에는 연결된 게임 계정·클랜·역할을 모으고 정보 펼치기와 선호 역할 관리를 제공한다.
- 인증된 게임 ID만 공개 프로필에 표시한다. 제공자의 내부 ID를 표시 이름으로 사용하지 않는다. 실제 외부 OAuth는 후속이며 QA 시뮬레이터와 구분한다.
- 부계정은 본인 또는 같은 게임의 공통 클랜 관계에서 허용된 범위로만 조회한다. 클랜 탈퇴·재가입·운영진 권한은 각각의 기존 서버 정책을 따른다.
- 가입 신청은 pending을 유지하고 결과는 최근 7일을 표시한다. 취소와 중복 요청은 서버 상태를 재검증한다.
- 계정 탭은 이메일·언어·자동 로그인·로그아웃·탈퇴, 게임별 관리와 가입 신청을 제공한다. 성별·출생 연도·가입일은 본인의 소개 탭으로 이동하며 계속 본인 전용이다. 자동 로그인은 약 30일의 세션 유지 설정이며 끄면 짧은 세션 정책을 적용한다.
- 계정/게임별 관리/가입 신청/자동 로그인 도움말은 제목에 연결된 툴팁으로 제공한다. 도움말 조작이 설정을 바꾸지 않는다.

## 개인 엠블럼

- 대표는 `account_personal_emblem_picks`에 계정당 한 행으로 저장한다. `클랜UUID:엠블럼키`를 최대 세 개 순서대로 선택하며 본인의 획득 원장에서 검증한다.
- 현재·탈퇴 클랜의 획득 이력을 게임별로 모아 보고 상세에서 게임·클랜을 구분한다. 마감 수상과 최초 달성일은 영구 보관한다. 클랜 통계의 개인 기록 공개 권한은 별도로 적용한다.
- 수상형/달성형의 분류·실루엣·계열별 최고 단계·관련 단계 상세와 날짜 색상을 사용한다. 고유 별명 대신 `10승 달성`과 같은 조건 설명을 표시한다.
- `clan_personal_emblem_picks`는 현재 클랜별 통계 조회와 기존 대표 선택의 출처로 사용한다. 폐기된 수동 5칸 배지 테이블을 다시 사용하지 않는다.

## 개인 상점

- 상단 현재 적용 모습과 구매 확인창은 실제 연동 게임 ID(없으면 Player)의 전체 네임카드를 사용한다. 오버워치 인증 ID를 우선하고 다른 인증 게임 ID를 차례로 사용한다. 상품 슬롯은 심벌·초상 프레임·배경·카드 프레임·칭호 중 해당 요소만 표시하고, 테마 세트만 전체 조합으로 표시한다. 상품 슬롯은 하나의 배경·외곽선 안에 이름/이미지/가격·버튼을 배치한다. 이미지는 키보드로도 선택할 수 있는 버튼이며 선택 테두리를 표시한다.
- 테마/심벌/초상 프레임/배경/카드 프레임/칭호 분류와 이름·설명 검색, 넓은 상품 6개/작은 상품·칭호 12개 단위 페이지 이동을 제공한다. 보유/정렬 선택 메뉴는 없으며 실제 카탈로그 등록일(created_at)의 내림차순으로 고정한다. 같은 시각은 상품 ID로 순서를 고정한다. 처음에는 가장 최근 미보유 상품의 분류를 선택하며, 전체 미보유 상품이 없으면 테마의 빈 상태를 표시한다. 분류·검색 변경은 첫 페이지로 돌아가며 구매 후 분류와 검색을 유지한다.
- 이미지를 선택하면 저장 없이 상단 네임카드에 해당 요소를 미리 입혀 본다. 상단은 설명 문구 대신 카드·상태/초기화 아이콘·적용/구매 버튼으로 구성하고 스크롤 중에도 유지한다. 초기화는 기존 저장 구성으로 돌아가며 선택/초기화 자체는 잔액·보유·선택을 변경하지 않는다. 적용 버튼을 눌러야 서버에 저장한다. 작은 심벌/초상 프레임은 좁은 슬롯을 여러 열에, 배경/테마는 넓은 슬롯에 배치하고 모바일에서 다시 줄바꿈한다. 마지막 행이 홀수여도 슬롯의 열 너비를 늘리지 않고 빈 열을 유지한다. 상단 눈 아이콘은 저장 전 미리보기 상태 표시이며 조작 버튼이 아니다.
- 보유 디자인은 프로필 꾸미기의 적용 버튼으로 저장한다. 상점에서 구매한 상품은 상단 미리보기에서 적용한다. 테마는 배경·카드 프레임·초상 프레임 3개를 함께 적용하고 심벌·칭호는 유지한다. 개별 부품도 자유롭게 조합한다.
- 기본 제공을 포함한 모든 보유/사용 가능 디자인은 상점 결과에서 숨긴다. 보유권·장착·프로필 꾸미기 목록은 유지한다. 구매한 상품도 즉시 목록에서 숨기고 상단 미리보기에서 적용할 수 있다. 보유 상품만 검색되거나 분류 내 미보유 상품이 없으면 빈 상태를 표시한다.
- 유료 칭호와 기존 Premium 프레임은 서버의 현재 가격·구매 조건을 유지한다. 프레임 표시 이름은 실제 동작에 맞게 ‘프리미엄 골드 프레임’으로 정리하고 기존 SKU/보유권은 보존한다. 구매 확인에는 실제 미리보기·사용 코인·남은 잔액을 표시하며, 구매 후 별도 적용한다. 개인 코인만 사용하며 중복/동시 구매·권한 검증은 기존 서버 정책을 따른다.
- 구매·적용 중 중복 요청을 차단한다. 실패는 구매 확인 안에 표시하고, 목록·분류·검색·미리보기 영역은 유지한다. 최초 조회도 최종 카드 배치의 자리 표시자를 사용한다.
- 미니룸·가구 상품·배치 기능·전용 경로는 제거했다. QA에서 housing_catalog/user_housing_rooms/user_housing_inventory 3개 테이블(91행)과 전용 함수 8개를 제거했다. 기존 코인 원장·현재 잔액·구매·네임카드·클랜 정보는 유지하며 자동 환급은 없다. 운영 DB 적용은 보류한다.

## 공개 범위와 데이터

- 내전의 비운영 화면에서 플레이어 네임카드를 누르면 현재 클랜의 `stats?player={userId}`를 연다. 소개·게임 계정·계정 대표 엠블럼을 개인 기록 상단에서 함께 보고, 전적·점수는 기존 열람 권한에 따라 제공한다. 소개만 허용된 방문도 통계 데이터는 받지 않는다. 운영 조작과 링크는 분리한다.
- 개인 기록은 현재 클랜의 게임 프로필 한 개만 표시하고 클랜 이름·직위를 숨긴다. 성별·출생 연도·해당 클랜 가입일은 통계 열람 범위와 독립된 소개 정보로 같은 클랜의 현재 구성원에게 제공한다. 소개 API의 `clanId` 지정 요청에서 방문자와 대상의 활성 소속을 확인한 뒤 기본 정보와 공개 범위 내 부계정을 추가하며, 클랜을 지정하지 않은 공개 응답·클랜 외부 방문·탈퇴 대상에는 추가하지 않는다. 계정 대표 케이스는 네임카드 밖의 한 줄 소개 아래에 두고 케이스 전체를 누르면 대상의 계정 엠블럼을 연다. 소개가 이미 같은 화면에 있으므로 네임카드 본문의 별도 프로필 이동과 케이스 링크 문구는 두지 않는다. 모든 역할이 멤버 검색·선택을 사용한다. 상대 링크의 사용자 ID를 본인으로 바꾸지 않으며, 본인 통계만 허용된 경우에도 상대 소개·기본 정보·대표 케이스는 표시하고 비공개 통계는 제외한다. 기본 정보 미수신 중에는 같은 세 칸에 자리 표시자를 사용한다.
- 로그인 방문자에게 현재 클랜·인증된 게임 ID·공통 네임카드 외형·한 줄 소개·획득 엠블럼을 기본 공개한다. 서버는 기존 프로필 열람 확인 후 외형과 게임 ID만 전달하며 미인증 ID·보유 목록·잔액은 전달하지 않는다. 별도의 공개 토글이나 공개 설정 저장소는 없다.
- 별도 상대 프로필 화면은 두지 않는다. 기존 `/profile/{userId}`는 공통 클랜 개인 기록으로 이동하고 공통 클랜이 없으면 본인은 `/profile`, 타인은 기존 계정 엠블럼 케이스로 이동한다. 통합 소개는 인증된 `/api/player-profiles/{userId}`에서 공개 필드만 받고 대상 변경·실패·재시도를 영역 안에서 처리한다.
- 이메일·제공자 내부 ID·잔액·계정 정보·편집 권한은 방문 화면에 제공하지 않는다. 누락·탈퇴 계정은 방문 불가, 비로그인 사용자는 로그인 후 원래 경로로 돌아간다.
- 게임별 꾸미기 선택과 수동 5칸 배지, 과거 공개 설정은 QA DB에서 제거됐다. 현재 테이블은 [스키마](../schema.md)의 계정 공통 선택과 [삭제·보존 감사](../../03-analysis/retired-db-storage-2026-10-26.md)를 기준으로 한다.

## 후속 범위

실제 게임 OAuth와 유료 결제는 별도다. 제거된 진열장·미니룸·수동 배지 개발은 재개 대상으로 두지 않는다.

### 탈퇴 확인 안내 (2026-10-27)

- 클랜 탈퇴는 현재 멤버 자격·직위·전용 기능 접근 종료와 계정·다른 클랜·내전 기록/통계·글/댓글·개인 자산 보존을 구분한다. 클랜장 위임과 같은 계정 재가입 승인 안내를 유지한다.
- 클랜싱크 탈퇴는 완료 시 로그인/개인 정보·연동/부계정·전체 소속·개인 자산 삭제를 안내한다. 클랜과 공동 경기 기록·작성자 연결을 해제한 클랜 게시판/공지/댓글·외부 게임 계정은 유지되며 기록 본문은 자동 정리하지 않는다. 일정·내전·투표·대진표·스크림 등의 운영 기록은 계정 삭제를 막지 않으며 작성자·호스트 연결만 해제한다. 기록별 운영자 게임 ID/표시 이름은 텍스트로 남고 프로필로 연결하지 않는다. 복구 불가와 이름/본문 보존을 확인창에 명시한다.
